## 容量与品质转移的交叉核对

固定提交 [Item.lua](https://github.com/PathOfBuildingCommunity/PathOfBuilding-PoE2/blob/ce566eac45ea8a86477f513c7ee65a1ebe60014e/src/Classes/Item.lua#L1750) 的编辑器路径对魔法侧别使用 `clamp(1 + 修正, 0, 2)`，稀有普通首饰使用 `clamp(3 + 修正, 0, 6)`；对应负容量得到下表。普通无显式词缀。该实现说明 PoB 模型，不独立证明游戏中的通货执行。

| 基底 | 魔法前／后缀上限 | 稀有前／后缀上限 |
| --- | --- | --- |
| Lament | 0 / 1 | 2 / 3 |
| Portent | 1 / 0 | 3 / 2 |
| Absent | 0 / 0 | 2 / 2 |

在 [CoE beta](https://beta.craftofexile.com/) 的 PoE2 制作页逐次点击材料和物品卡，核对可见词缀组数及动作次数，获得以下观察：

- Lament：蜕变后只有一条后缀，增幅不增加词缀或动作；富豪可升级为稀有，之后崇高填至二前缀三后缀，再点一次不增加动作。
- Portent：蜕变后只有一条前缀，增幅不增加动作，富豪可追加。另从普通基底点金得到二前二后，再崇高达到三前二后，满后不增加动作。
- Absent：普通蜕变记为一步，变成零显式词缀魔法装备；富豪才增加第一组，随后崇高填至二前二后，满后不增加动作。另从普通基底点金直接得到二前二后，只记一步，再崇高无新增动作。

只统计容量、品质转移和是否执行，没有采用随机生成的具体词缀、价格或概率。网页有同名隐藏控件，早期自动定位未真正操作装备；这些点击不计入观察，最终均以实际物品卡及动作次数为准。固定 PoB 容量与上述工具行为一致，作为当前模拟规则依据；尚不是游戏真机结论。

## v102 实现与剩余边界

起点保留原基底 ID 和完整共同行、唯一技能行，不另造基底、不存第二份变体编号。搜索必须主动选择技能；导入与恢复继续按三服独立词典核对完整原文，缺失／歧义不猜测。空白起点可以声明技能显示等级，不能预设其他固有属性数值。方案复用只带目标和策略，不带入模板技能。

显式目标、条件指引、准备路线和费用使用实际容量；Absent 普通零词缀蜕变保留独立步骤，后续富豪仍按稀有容量挑选。高级／完美蜕变的零容量行为没有本轮直接观察，明确拒绝。旧版本项目不能夹带新的三基底语义，完整未来历史也须验证。

神圣、催化、孔位、技能等级／辅助孔材料与已有特殊待揭示限制继续保留，不能因为基底入口放开而推定材料资格。已支持的显式追加、移除、保证制作和骨骼仍各自验证侧别容量、来源与冲突，操作不重选技能。技能变体的生成／重选途径及概率、上述特殊材料和游戏实操仍须继续核对；候选顺序或数量不代表概率。用户没有催化剂样本或相关经验，不依赖再次索要样本推进。
