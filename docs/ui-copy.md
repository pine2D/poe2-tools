# 界面文案规则

2026-10-23，从用户已确认的 v4 文案规则整理。适用于网站、扩展弹窗、阅读侧栏、站点设置与 CoE 自有界面；相关生产页面已随网站 0.10.0 与扩展 0.11.0 公开发布。产品能力以 [PRODUCT.md](../PRODUCT.md) 和对应验收记录为准。

## 基本规则

1. 一处只说一件事。标题说明内容，正文说明操作或限制，不再换句话复述标题。
2. 按钮写动作，状态写结果。例如“删除”“开启”“已开启”“生成失败，选项已保留，请重试”。
3. 同一条说明放在需要做决定的位置；独立入口各自保留必要事实。发送提醒靠近翻译操作，游戏加载待验收靠近下载，非官方声明保留在署名和页脚。
4. 删理由铺垫、安慰句和用户无需了解的实现历史。保留具体下一步，不写“这是正常的”来掩盖限制。
5. 事实、范围、限制与后果一律保留，可以说短。仅 Beta／PoE2 英文、桌面 Chrome、国服术语、自备 Key、未加密的本机存储、未验收项目、权限收回或保留，均不得因精炼消失。
6. 不加未经证实的数字、功能、承诺或译名。设计原型的版本、大小、段落数和服务名不能硬编码到生产文案。
7. 少用“不是……而是……”、揭晓式破折号、“如下图”“以下几项”等空转铺垫；长并列拆成用户可以扫读的信息。

## 常用表达

| 场景 | 写法 |
| --- | --- |
| 导出选项 | 每行译文下附英文原文，文件会变长。 |
| 游戏加载限制 | 尚未在游戏里实测加载。 |
| 自动划词说明 | 术语先按国服词典对照，整句要点“翻译”才会发送。 |
| 发送前确认 | 按当前选择显示段落数、估算字数、目标服务与不发送内容；不得用原型固定值代替。 |
| 常用站删除 | 写清删除规则是否收回该站访问权限，并说明常用站仍留在列表。 |
| 不能识别的装备行 | 给出行号和核对动作，保留完整原文；不暗示删掉未知行即可安全导入。 |

本机词典转换、读取网页与发送给服务商分别描述，不能统称“都不联网”或“都会上传”。术语命中、格式通过与整段译文准确性也要分开表达。

## 必须保留的信息

- 权利声明保留 Grinding Gear Games、腾讯、Craft of Exile 的名称及非官方关系，不因字数缩减丢失权利人。
- API Key 不内置；隐私说明保留本机存储、未加密与页面读取边界，主动发送的文字及必要语境按实际实现说明。详见[隐私说明](chrome-extension/privacy.md)。
- 扩展“生效中／部分生效／未生效”与网站介绍同词，并由实际状态决定。
- 工程或原型验收不能写成语义质量通过；`.build` 游戏内加载效果仍待真机验收。

## 生产迁移

改字符串时同步相关视图、真实行为的测试断言及字体收字来源；不能为了让旧断言通过而保留重复提示，也不能只改文案掩盖行为缺失。新增衬线字符按字体流程重建。扩展文案改变 ZIP 时按发版规则升版本，已发布的版本（当前为 0.11.0）不替换 ZIP。
