## 本项目的应用边界

用户与项目约定优先于技能的默认建议：

- 技能只指导开发，不打包进 Chrome 扩展，也不在用户浏览器执行。
- 不因设计技能建议而引入远程字体、动画库或生产依赖；扩展继续使用包内资源和已有工具。
- CoE 有广告及后台网络，验收等待可观察的控件／结果稳定，不强求全站 networkidle。真实扩展仍通过 agent-browser 实装验收；Playwright 示例不会被当成已执行结果。
- 已检查 webapp-testing 的 helper 和 examples：helper 可运行传入的 shell 命令并管理本地进程，仅限可信命令。示例输出路径、网络等待和依赖不直接套用，不在本次安装中执行。
- 自动化只使用自造文本；不用用户私人装备制作入库 fixture。
- 更新需重新审查上游变化和许可，更新固定提交与文件哈希，单独提交；不自动跟随 main。
