## 等阶差异与回归

首次设计样本写T5，但原站实际显示Dexterity5为T4，导入时未拒绝。修正样本为T4并重新执行三组英文控制及中文矩阵。新增回归先证明错误等阶会误放行，再对本档案限制等阶4及范围21–24；最终包实站错误T5样本的填入按钮disabled，并明确提示原因。不能从其他装备同名词条或mod ID末尾数字直接推断等阶。

三个新增正向回归先失败后修复，另覆盖品质超限、第三孔、未验收面板、错误前后缀、未知基底、腐化及错误等阶／范围。最终32文件307项相关测试通过；最终魔法样本使用简称“弓”，普通／稀有使用“弓类”，两类写法分别完成实站导入对照，item-core与扩展类型、全仓Biome、构建及包检查通过；未重跑全仓慢测试，最近完整基线仍0.1.95。旧网站转接名单及武器属性禁用边界未改变，不恢复旧制作引擎开发。

最终ZIP12文件与dist、实装解包目录逐文件一致，六项词典来源哈希匹配，交付副本与ZIP逐字节一致；仅storage权限，无新增生产依赖。
