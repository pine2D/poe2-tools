## 结论与证据范围

- 用户选定的“目录＋当前段＋异常”已落地，原文旁模式只挂载当前段；“仅侧栏”保留全文结构。
- 独立划词由弹窗启用当前页，选择后点击才翻译；不要求侧栏保持打开，复用同一设置、术语、缓存与接纳规则。
- 本轮真实模型 API 请求为 **0**。本机合成服务共新增 **7** 次请求，包含协议失败、取消、中断及一次未成功终止 worker 的驱动尝试；原有 15 次不计入本轮。合成译文只用于工程与交互验收，不能证明语义准确率通过，旧质量失败结论保持。
- 浏览器为隔离资料的 Linux/WSL Chromium 149，仅加载当前扩展，不改用户日常 Chrome。真实站点结构、固定本地合成响应与自动回归分开报告。
