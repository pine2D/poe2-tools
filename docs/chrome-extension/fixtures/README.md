# 扩展实站验收的自造流程

`two-step-lightning-route.json` 是本项目通过新版CoE公开界面自行配置、用原生Export Simulation导出的流程，2026-09-25在扩展0.1.24下执行。文件只增加缩进，保留原导出字段；不含用户私人物品，也不是原站规则库或数据文件。上游格式和动作身份可能变化，不把它当作稳定API。

## 流程与核对点

- 起始：普通符文法器、物等100，无词缀。
- Step 1：普通蜕变石；闪电抗性条件78满足则结束，结束优先级0；否则通过优先级1的连线进入Step 2。
- Step 2：普通增幅石；同一条件满足则结束，否则重新开始。
- 运行：fixed／items／10，保存结果。

0.1.27 已独立验证重新导入：流程模拟 → 新建模拟流程 → 导入一个流程 → 粘贴该 JSON → 继续。再用“导出模拟流程”取得 JSON，与本文件解析后逐字段完全一致。不要使用“载入 → 全部导入”，后者要求批量导出数据，会拒绝单个流程并给出中文指引。复测也可按上述动作重建；选择条件后先检查编辑状态，应用后再次核对导出中的requirements，不能只看界面文字。随机结果不会每次相同，完整证据和未解决问题见上级compatibility.md。

样本中的两个随机步骤ID只表示连线关系，不关联个人身份；action里的legacy标记是原站导出格式，不表示扩展使用旧域名。

## 两个条件组的调查样本

`two-group-resistance-route.json`由原生UI在两步样本基础上配置并导出：第一步结束要求含or(78,77)及not(80)，matches均为null。它是待继续分析的调查样本，不是已经验证符合预期逻辑的制作方案。实测运行10件全部通过第二步结束；第一步未直接结束，原因与数字匹配控件事件仍待核对，见compatibility.md的两条件组记录。

`two-group-match-one-route.json`是上述样本在无扩展英文原站以真实键盘把第一组匹配数量设为1后的原生导出，保留字符串`"1"`。最终0.1.52中文包从null样本重复键盘编辑，导出逐字一致；两边运行均完成10件且第一步可直接结束。它验证这一配置链，不代表所有分组逻辑、阈值或循环均已验收。

## 显式回边调查样本

`explicit-backedge-no-start.json`为原生UI生成的Step1→Step2→Step1无动作回边，没有显式起点，会触发起点选择错误。`explicit-backedge-property.json`是最终0.1.53包选择Step1起点并添加能量护盾属性后的原生导出；属性tier仍为null，不能将它当作指定阈值的模板。

这是调查样本，不是可完成的制作方案。已有实测表明无动作回边不会自动结束，需要原生停止按钮；不要当作自动化批量执行样本。全部字段保留原生导出，仅格式化JSON。循环运行、手动停止、启停导出以及数值未保存的边界见compatibility.md。


`silk-slippers-zh-CN.txt`为自造稀有丝绸便鞋高级文本：品质20%、一个空孔、T3护盾40和T6闪电抗性18。`silk-slippers-native.json`是无扩展英文基线的原生导出，仅格式化；0.1.57最终ZIP中文转换后的原生导出与该基线逐字一致。不是用户私人物品，也不包含站点规则库。


`silk-slippers-speed-zh-CN.txt`在自造便鞋上加入无括号范围的20%移动速度T4前缀；`silk-slippers-speed-native.json`为对应英文样本的原生Export，仅格式化。0.1.58最终ZIP完成中文预览与原站导入，导出逐字一致。


## 翠玉项链导入样本

`jade-amulet-zh-CN.txt`是自造稀有翠玉项链：敏捷固有属性12(10-15)、敏捷后缀24(21-24)T4、闪电抗性18(16-20)T6。`jade-amulet-native.json`及带`normal`、`magic`后缀的两份JSON分别为无扩展英文原站的稀有、普通、魔法导出，仅格式化；普通只保留固有属性，魔法另含敏捷后缀。0.1.62最终ZIP完成三种中文结构的导入，原始导出均与对应英文基线逐字一致。不是用户私人物品，不含站点规则数据库。
