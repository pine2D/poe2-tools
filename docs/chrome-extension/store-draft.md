## 名称与简述

名称：PoE2 中文助手

简述：为新版 Craft of Exile 的 PoE2 页面提供国服简体术语，并在攻略页按国服术语显示原文与翻译。

## 详细说明

PoE2 中文助手是非官方扩展，帮助玩家阅读和使用 PoE2 英文工具与攻略。

- 在 beta.craftofexile.com 的英文 PoE2 模式下显示国服简体术语，支持中文搜索和高级装备文本转换。
- 在攻略页点击扩展图标，再点击“翻译此页”，在侧边栏查看正文与术语标注；支持 Mobalytics 的 PoE2 构筑页、poe2.com，以及通用正文提取。
- 整段翻译需要用户自行配置翻译服务 Key，默认 DeepSeek，也支持 OpenAI 兼容接口。未配置服务时仍可阅读原文和术语标注。服务商可能收取 API 费用。
- 只在用户主动读取时提取正文，不自动翻译所有浏览页面。PoE1 不在支持范围内。

本项目与 Grinding Gear Games、腾讯、Craft of Exile 或攻略网站无隶属或官方合作关系。游戏文本及第三方资料权利归各自权利人；译名来源与已验收范围见项目文档。

## 单一用途

把 PoE2 英文工具页面与攻略中的文字按国服术语显示为简体中文。

## 权限用途

| 权限／范围 | 用途 |
| --- | --- |
| storage | 在本机保存功能开关、翻译偏好；攻略 Key 与译文缓存使用扩展来源的 IndexedDB。 |
| activeTab | 用户点击扩展时临时获得当前页访问权，以读取本次选择的攻略。 |
| scripting | 用户请求读取时在当前标签页注入包内取文脚本；不注入远程代码。 |
| sidePanel | 显示原文、术语标注、中英对照、翻译进度与设置。 |
| beta.craftofexile.com 内容脚本 | 仅在该站提供 PoE2 术语显示、中文搜索和装备文本转换；其他网站不自动注入此脚本。 |

## 数据使用说明

攻略翻译会把用户选中的正文段落和本段术语发送到用户配置的服务商；“测试连接”会向同一服务商发送一句简短测试文字。不要在商店表单中误填“完全不发送页面内容”。不发送页面网址、Cookie 或账号信息，不含统计 SDK，不出售数据。

Key 与译文缓存保存在本机扩展存储，未加密；可在扩展设置中清除。网页与注入网页的脚本不能读取该扩展来源的 Key。服务商对所接收文字的处理以其条款为准。

隐私说明拟用地址：`https://poe2-tools.pine2d.com/extension/#privacy`。送审前必须核实线上已部署 0.5.0 对应说明；本分支文件不等于线上内容已更新。详细源文档为 `privacy.md`。
