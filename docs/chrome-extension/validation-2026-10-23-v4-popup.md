# v4 第一批：共享样式与真实弹窗验收

2026-10-23，`feat/v4-ui-migration`。本轮只交付共享颜色、通用按钮、分隔线、方形开关与真实扩展弹窗；阅读侧栏、设置、站点管理、CoE 浮层和网站的完整 v4 布局仍待后续批次。

0.11.0 是本地开发候选，尚未公开发布；公开版本仍为 0.10.1。本轮没有调用真实翻译服务，既有整段译文语义质量失败结论保持。工程、浏览器与语义质量分别判断。

## 改动与约束

- 生产 token 继续统一维护在 `packages/ui-theme/src/tokens.css`。CoE Shadow DOM 与独立 404 页的最小内联子集同步已有同名色值，由一致性门禁约束；不把原型 `:root` 注入宿主，不改布局或适配逻辑。
- 弹窗宽度为 360px，CoE 当前页状态与两个开关置前；翻译入口仍使用原控制器，保留全部绑定 ID、状态语义、存储及消息路径。
- 开关仍是原生 checkbox 加 `role="switch"`，左侧方形外观由 CSS 绘制，整行 label 提供点击区。
- 标题、标签和按钮使用独立衬线子集；说明、声明和版权继续使用无衬线。衬线收字覆盖静态标签和动态按钮文字。
- 钢蓝按钮保留装饰内边，清晰外边采用 `--control-edge: #94a1ae`；青铜只作边框。旧构筑标记色的对比度计算同步新提示框背景，避免只改视觉而沿用旧背景计算。
- 阶段表与首页示例中残留的青铜文字改用文字色 `--gold`；对展开、悬停、待核对及半透明标记的实际组合补充对比度回归。

## 独立终审

一次只读独立审查发现两项需要修复的问题，均已完成对应回归：

1. 矮屏中正文固定 600px，根节点裁切导致页脚不可达。实际 410px 高弹窗复现失败；最终根节点提供自然高度，正文按实际视口封顶滚动，根节点不预留滚动条槽位。复验同时确认正常弹窗不会锁在 Chrome 初始的 25px 高度。
2. 旧阶段表与首页示例仍把青铜边色用于小字。新增回归在半透明标记底上测得 3.77:1，改用文字色后全部真实背景组合通过 4.5:1 门槛。

同时按本轮文档整理要求校正产品／设计工具的旧状态描述，并将 0.10.1 的摘要链接固定到对应 tag，避免误读当前分支的 0.11.0 候选记录。终审期间的一轮完整门禁因需要修复而主动停止（130），不计通过；修复后重新运行完整门禁；新回归测试一度使用超出现有站点 TypeScript 标准库的 `findLast`，已改用受支持的读取方式，站点类型检查通过，没有升级依赖或放宽配置。

审查中列为本批范围外的完整布局迁移、Windows／输入法／读屏／游戏加载和真实服务质量，均保留原有边界；不是默认通过，也不代表整体目标已经完成。
