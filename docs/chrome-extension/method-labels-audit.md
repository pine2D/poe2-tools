## 实站

最终ZIP解压实装后，原站导入自造稀有粗制弓JSON，展开“生成”菜单，三个选项均可见且显示简体；分别实际点击，最后选择值为[10,2]。切回通货并选择崇高石后，“可用预兆”标题实际可见。通过扩展真实popup文档切换双语，生成菜单和预兆标题保留英文对照；停用恢复英文，重新启用并关闭双语后恢复纯中文。双语及停用前后全部生成／预兆选项的value/item数组相等。

首轮导入后立即查询菜单早于原站异步渲染，等待实际控件出现后继续。连续点击时遇到原站悬浮提示遮挡，移开鼠标后再点，未强制绕过遮挡。设置脚本最初在停用状态操作已禁用的双语开关，导致重新启用后仍为双语；改为先启用、再关闭双语后通过。不将这些工具操作问题记为扩展缺陷。

仅核对选择器和显示恢复，没有点击装备执行生成或消耗预兆，不宣称验证原站制作概率。模拟器使用相同控件结构，但本轮未重新实测其生成菜单。
