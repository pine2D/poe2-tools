# 0.4.4 词缀翻译系统整改验收

日期：2026-10-20。本地候选，不代表公开发布或 Chrome 应用商店状态。基线为 0.4.3（`1f19380`），运行环境是 WSL 中 Chrome for Testing 151.0.7922.34，使用专用临时配置加载真实扩展构建目录；未以脚本注入代替扩展运行。

## 变更范围

原始词缀快照与旧 `.build` 投影分离；固定数值不再泛化成变量。页面显示、中文检索和装备反向转换接入同一个确定性核心，保留来源、数值顺序和真实歧义。普通 UI 层保护完整词缀语义区域，未知句子不再被拆成部分中文。契约、来源和更新步骤见 [translation-contract.md](translation-contract.md)。

没有改造制作引擎、建立基底／词缀准入名单、复制其他扩展词库或使用 DeepSeek。原有网站与 `.build` 调用方保持兼容入口。

## 来源和自动化验证

- 三服分别使用官方静态 stats 端点，记录各自抓取时间、URL 与 SHA-256。接口未报告游戏版本，使用 `unknown`，不把 CoE 的内容版本当作三服同步证明。
- 简体快照 3,704 条，加 2 条有来源依据的展示变体；3,706 个简体展示条目全量可译，改变源模板固定数字不会误命中原模板。
- 简繁合计 7,420 个输入条目的正确反向候选均保留；同一中文对应不同英文时仍拒绝自动唯一化。30 条独立冻结句式覆盖攻击、护甲、药剂、咒符、召唤生物、条件、地图与负例。
- 上游缺口独立锁定：简体 636 项未配对标记；繁体 2,314 项未配对、1 项占位符不一致、33 条仍为英文、6 组同英文不同译文。计数沿用构建器 ID／语境发生项口径，不等于当前 CoE 制作池漏译数。
- 最后的 `<br>` 修复前，完整 `pnpm verify` 退出 0：655 文件、5,817 项通过，1 项因缺少本地真实 `.build` 样本跳过；测试耗时 1,156.99 秒。类型、格式、打包、发布记录校验、全仓构建、词典及历史制作目录检查均通过。保留 4 个既有 CSS specificity 警告及历史工坊 chunk 大小提示。
- 最后的 `<br>` 修复先红后绿，相关 23 项通过；最终代码 `pnpm verify:active` 退出 0，133 文件、1,482 项通过、1 项同原因跳过（56.36 秒），类型、打包校验、全仓构建和数据检查通过。未在该 DOM 修复后重跑冻结制作的全量长测。
- 首轮完整检查因新增覆盖测试导入 `.mjs` 缺少声明而类型失败；补充构建脚本类型声明后重跑通过。来源缺项基线最后补充并格式化后，单独重跑 33 项覆盖测试通过。

## 真实浏览器

### 用户手套链接及显示矩阵

使用用户提供的四词缀稀有手套链接，物等 50，生命 95、护甲 78／护盾 23、护甲护盾提高 63%、冰霜抗性 6%。网页 201 个 `.modGroup .stat` 节点中，9 个位于原站隐藏区域，192 个符合扩展支持边界，涵盖 95 个不同文本。

| 状态 | 192 个支持节点 | 原英文视觉状态 | 原生复制 |
| --- | --- | --- | --- |
| 停用 | 无中文宿主和诊断 | 显示 | 对照基线 |
| 中文 | 192 全部译出 | 192 隐藏，DOM 保留 | JSON／PoB 与基线逐字相同 |
| 双语 | 192 全部译出 | 全部显示 | JSON／PoB 与基线逐字相同 |

普通／紧凑 × 经典／高级四种原站设置，分别在中文与双语下再次检查，8 个组合均无缺译，原生 JSON／PoB 与同布局停用扩展时逐字一致。不同原站布局的 PoB 格式不要求彼此相同。截图检查包括物理／火焰／冰霜／闪电附加攻击伤害、属性需求降低、护甲作用于元素伤害及概率创口句式。

默认高级布局的用户装备复制摘要：JSON SHA-256 `f904ec39118d0f50a70b9a65c94a9c888f878e39e8bb3938a53b53ba97da2c1b`；PoB SHA-256 `f5c0cfa3ad9030b362aa6c7414c2a3dc1e281ab772debbe19409a4099b60a133`。原文仅留在本地忽略目录，不入库。

中文“属性需求降低”候选填入 `#% reduced Attribute Requirements`，待原站异步筛选完成后，与停用扩展直接英文查询都只显示 `group_23`。点击中文词缀展开 7 个等阶并收起，前后原生 JSON／PoB 一致。

### 跨类别导入

使用既有自造的稀有弓、红玉戒指、法器、权杖高级文本，4 件均完成中文预览 → 英文填入 → 原站确认，预览前后原文保留，开关前后 JSON／PoB 逐字一致。与历史原生 JSON 比较，差异仅为 `ig:null → 0` 和新增 `ms:0`；不把历史版本记录称为当前原站完全逐字基线。弓、戒指、权杖页分别 143、177、66 个支持词缀节点均译出。

法器页的 152 个支持节点初测有 1 条未译：公开 DOM 用 `<br>` 将 `an` 与 `additional` 分开，`textContent` 却连接成 `anadditional`，而官方词典已包含完整句。补充通用 DOM 换行读取后最终包 152/152 译出，原句 `innerHTML` 与 `textContent` 均与修复前一致；停用、中文、双语三态的原生 JSON／PoB 逐字相同。不添加句式别名，也不改变原节点。

腰带预览完整转换并保留原站兼容性提示，原站仍拒绝 `Has 2(1-3) Charm Slot`；未删除属性或绕过确认。

### Data 全列表对照

通过公开页面选择 Data → Modifiers → ITEM，只观察公开 DOM，不读取原站内部数据文件。列表共 8,464 行，350 行为空；6,634 个非空不同文本与整改前快照的文本集合完全相同。最终包 6,024 行有译文，去重后 4,821 个可译、1,813 个未命中。对同一集合比较，新增可译 265 个，原来有译文而本轮缺译 0 个。

这个列表包含历史及不同领域文本；上述是页面语料覆盖，不能解释为当前 PoE2 制作池或全站覆盖率。未知条目保留英文并记录 `unmatched`，不能仅凭这个状态把原因认定为官方缺项。

### 验收脚本与环境边界

一次经典布局加载超过默认 25 秒等待，稍后页面已正常加载；新的隔离配置完成全部矩阵。没有证据将超时归因于扩展。本地扩展重载后曾因隔离配置未启用开发者模式而停用；通过 Chrome 原生开发者开关恢复后确认版本 0.4.4 启用。搜索脚本最初误查 Shadow DOM 内按钮，实际候选在 light DOM；另一次未等原站异步筛选完成就比较，修正等待条件后通过。最终复制复验曾在 PoB 槽读取到上一条 JSON；保存原始失败后，增加实际剪贴板格式到达条件，不以错误槽位作为停用基线。跨类别导入脚本也须以 `dialog.open` 判断关闭，不能以隐藏输入框仍在 DOM 中判定失败。

未知语义容器被普通 UI 层局部翻译的问题已由最小 DOM 测试复现并修复，但没有在用户原来的浏览器会话中取得当时 DOM，不能断言这就是每张截图的唯一原因。在最终法器页 1,266 CSS px 窗口测得双语页面横向内容宽 1,347 px，停用及中文为 1,251 px；窄窗口双语仍有横向溢出，本轮未声称全布局适配完成。未进行 Windows 原生 Chrome、游戏真机、全分辨率、全装备或完整模拟路线验收；既有原站咒符栏、技能重算等边界继续见 [upstream-issues.md](upstream-issues.md)。
