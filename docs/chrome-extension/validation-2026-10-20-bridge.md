# CoE 与攻略翻译衔接验收（2026-10-20）

本轮按[衔接契约](translation-bridge.md)实施，产物为 **0.6.0 本地候选**。共享词缀、通用提取、语境和缓存工程已接通；同期真实正文对照未通过语义门槛，不能声称整段质量改善或可公开发布。旧 0.5.0 失败周期与 CoE 0.4.4 参考证据保留。

## 工程变更

- 攻略只读取独立简体词缀投影与名称投影；来源身份、原始模板、冲突裁决签名可追溯，CoE 界面译文和繁体输入数据不进入正文提示。
- 段落、列表、表格和选区先进行完整词缀分流；未知、歧义和截断明确保留，显式换行须全部命中才组合。正常正文不做单词拼接替换。
- 语境只来自用户选定范围，在缓存过滤与拆批前生成；引用的完整词缀有独立证据和恢复映射。缓存身份包含语境、结构、处理规则及投影。
- 完整请求结束后才落缓存；用量缺字段不补零，截断警告随缓存保留；不自动重试服务请求。

## 固定真实服务周期

本周期冻结的执行上限为 72 次请求和输入输出合计 400000 tokens。全部材料预先冻结，开发双组分别含 82 块（77 种原文），盲测 8 篇/80 段、重复 20 段两次与最终浏览器 8 次均预先登记。全周期最坏预留为 476875，初次预检因此保持零请求；用户明确同意改为每阶段完整核算、按实际用量判断下一阶段，总上限不变，不删样本。

开发对照使用同一 `deepseek-flash`、非思考模式、temperature 0.2、max_tokens 4096；同期基线为冻结 `c1f2e10` / guide-v7 与原 0.5.0 名称词典，候选为本轮 guide-v8 与新投影。共 **22 次**请求，输入 **33379**、输出 **7645**，合计 **41024 tokens**；无失败、无自动重试、无缺失 usage。两组各 82/82 输出完整，段号与自动术语、数值、保护片段检查全部通过。开发集没有整块确定性词缀命中，因此这组统计只评估正文，不能代表新增词典分流的覆盖率。

明确失败包括：候选给“最多 300%”增加了“次”单位；把准备五词缀地图写成“洗至五词缀”；石板镶嵌动作仍被写成“刷镶嵌目的地”；部分稀有怪密度表达被写成稀有度。原文数字本身虽未丢失，数字与对象/单位的关系仍可能错误。候选没有显示出正文整体优势，不能以词典或自动检查成绩抵消这些错误。

用户随后允许放宽至 100 次请求并相应放宽 token 额度；本周期因语义质量而非预算停止，没有启用新增额度，也未改写冻结账本。
