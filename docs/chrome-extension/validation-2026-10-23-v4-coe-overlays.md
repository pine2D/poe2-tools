# v4 第三批：CoE 自有浮层验收

2026-10-23，`feat/v4-ui-migration`，承接第二批 `5eae55c`。本批迁移 CoE 中文候选、装备转换面板与语言提示。0.11.0 仍为未公开本地候选，公开版保持 0.10.1；网站布局留在后续批次。

## 实现边界

- 自有浮层采用黑底直角、钢蓝主操作与板岩分隔；青铜渐变只标识选中候选和当前步骤。词典匹配、转换规则、原站授权与权限不变。
- 候选中文／英文分两行，任意名称保持系统无衬线；按钮留在文档中，完整 `aria-label` 保证名称，内部 Shadow DOM 隔离宿主星号样式。条件输入框的文档内 ARIA 引用与原有焦点模型保留。
- 装备步骤为“预览核对→填入英文→原站确认”，分别标明你／你／原站；步骤仅映射既有转换状态，最后一步不会由扩展标记完成。填回后仍须用户操作原站确认；未知行、编辑失效、恢复原文回到核对步骤。
- 固定标题、按钮、步骤、列标题、清单标签使用 L1 子集；离线重新生成后所有字体字节未变。L1 557 字、104,228 字节，预算 131,072 字节；弹窗 44,888 字节、侧栏 69,740 字节及网站分片保持。
- 完整“非官方”署名、版权声明、“已识别不等于能导入”与原站最终判定保留。没有新增数据源、依赖或宿主全局颜色／字体规则。
