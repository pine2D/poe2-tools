## 1. 共用来源，按用途投影

原始词缀保留固定数字和原始身份，不回退到 `.build` 的数字归一化投影。CoE 界面词、繁体输入和攻略正文名称分开打包；共用已有 source 数据，不复制同类工具数据或规则。

词条应能追溯到来源身份、语种、用途、中英文、占位顺序、来源摘要和规则版本。不同身份或词义不能只因英文相同就丢弃；CoE 的显示优选不能直接成为攻略正文的词义优先级。词缀 `translated/unmatched/ambiguous/source-untranslated` 与正文 `confirmed/candidates/hint` 分别保留。

人工词缀裁决绑定审阅时的英文、中文及占位顺序签名；同 ID 文本变化时构建报错，必须重新审阅。source version 为 unknown 时不能拿抓取日期充当版本。数据来源登记先于新增采集。

## 2. 保留结构与确定性路由

提取器只读 DOM，保留原文、角色、实体/原样片段、显式换行、标题/列表/表格关联和截断诊断。来源文档保留，不因路由或保护改写原文。短词缀在已选正文范围不因 40 字门槛丢失，导航和交互控件仍排除。

处理顺序为原样保护 → 整个单元精确词缀解析 → 显式换行子单元解析 → 正文路线。段落、列表、表格和选区均可走确定性路径，不再仅限 `modline`。整单元失败时，只有所有非空子单元均可确定翻译才整块输出；不能部分替换后丢掉剩余文字。

明确词缀块未命中、来源未译或有歧义时原样保留并说明原因，不用模型冒充词典。一般叙述未命中继续正文路线，百分号或数字不构成词缀判断依据。`25% reduced Attribute Requirements` 可本地译成“属性需求降低 25%”；`Prefer gloves with ...` 仍要翻译完整建议关系。

## 3. 正文局部证据

沿用正文语境匹配器的词形、同形词候选、专名与行话规则。模型只接收当前块相关词条及明确界定的完整词缀引用，保留可读英文与对应译文；不注入整个词库，不做无对齐的全局替换。

数字、URL、代码、明确未知实体逐字保护；真正固定还原的引用携带原文和目标映射，验证缺失与重复。`Use more Life flasks` 的普通 more 不套用“总增”。未确认词义保持候选/原文，模型结果不回写权威词库。网页原文与上下文仍位于不可信数据边界内。

## 4. 稳定语境、缓存与费用

在缓存过滤和拆批前，从用户选定范围构造稳定原文语境。首次、部分缓存与单块重试必须得到相同语境；不取选区外文字，不拿上次译文作事实。标题/列表/表格关系由提取器提供，语境的选取与长度边界由 guide-core 负责。

缓存覆盖实际依赖：相关词典投影及规则版本、块角色与实体/保护范围、语境指纹、服务商/模型/参数、提示/输出协议与检查版本。CoE UI、繁体导入变化不应清空无关简体正文缓存。旧 Key 与缓存保留，通过身份隔离旧结果；缓存命中不提升质量等级。

发送估算包括实际提示、术语、语境与输出预留。单段重试保留用户范围，失败也计入额度；没有自动付费纠错循环。停止/切页/取消后旧响应不能写回新文档。

## 5. 用户状态与检查边界

显示“词典译文”“机器译文”“待核对”“原样保留”；详情区分未命中、歧义、来源未译、提取截断。缓存只说明来源。

自动检查段号/数量、保护内容、数字符号/范围、明确术义约束。动作、对象、否定、条件、顺序、遗漏/新增事实与数字所指对象依靠带原文语境的独立语义审读；术语出现和数字多重集一致不能代替它。

## 固定验收矩阵与新 API 周期

离线覆盖完整词缀、引用、普通 more/less、未知长专名、同形词、正负数/范围/单位、BR、多行短块、表格、选区、截断，以及缺段、取消、重试和用量缺字段。CoE 覆盖经典/高级、简体/双语、普通/紧凑、搜索、导入、动态更新与原生 JSON/PoB 复制。攻略覆盖整页/选区、阶段、缓存、停止与异常。

用户本次授权最多 **72 次真实请求且累计输入+输出不超过 400,000 tokens**，任何一个达到即停止。独立账本从零开始，不继承旧周期余量；不新增候选或改模型反复试验。

| 阶段 | 次数硬上限 | 固定范围 |
| --- | --- | --- |
| 同期基线/单一整合候选 | 40，各最多 20 | 既有 82 个开发输入块，77 种原文；同源同模型参数 |
| 盲测 | 16 | 原封存 6 篇/60 段，加开发前封存的 2 个通用页面各 10 段，共 8 篇/80 段 |
| 稳定性 | 8 | 预定 20 段再重复两次，含通用页面 |
| 最终浏览器真实服务 | 8 | 最终包入口、部分缓存、单段重试、停止；沿用已登记语料 |

发送前离线核算完整批次及保守 token 预留。若上限不足以覆盖约定材料，不发请求、不删样本凑预算。所有失败、重试和修订均计数；请求前持久预留，usage 缺失或不完整不释放未知用量。基线与候选的结构/术语/语义分别统计，真实原文及输出只存忽略目录。

开发门槛为零重大语义错误、明确术语/数字/结构检查全部通过；未通过即停止，不消费盲测/稳定性。盲测需至少 95% 无需修改且自然理解，重大错误仍为零；全部重复计分，不能挑最好一次。保存问题跨度和理由，独立复核 major/ambiguous 及抽样 pass；AI 审读不冒充真人专家认证。

预算是支出上限，不是质量承诺。工程衔接可通过而正文质量失败；失败时保留候选和原因，不降低门槛、不发布。仅声明本轮实际验证的可访问文本 DOM；PoE1、图片/视频、不可访问 iframe 和未测试 Windows 真机均不外推。
