# 通用攻略阅读与翻译范围契约

2026-10-21：用户已批准研究建议并要求实施。基线为 0.6.0 / `16300b7`；本文规定实现与验收边界，实际通过范围见[阅读体验验收](validation-2026-10-21-reading.md)。旧正文语义质量失败结论保持，工程整改不等于语义验收通过。本轮只生成本地 0.7.0 候选，不推送、部署或更新 CWS。

## 证据与目标

0.6.0 在用户的 domistae 攻略总览页仅提取终局卡片 6 段、1033 字符，仍标为全文。通用根选择只比较单个 article 等容器；全局 header 排除又丢正文标题。范围由残留 Selection 隐式决定。离线控制器探针确认内部 m 标记虽报警仍显示、可复制、入缓存；编码标记与未知占位也有遗漏。

目标流程为“读取并预览范围 → 用户开始翻译 → 原文旁阅读，侧栏管理”。同一份结构化正文与合格译文服务两种视图，切换视图不触发翻译。

## 全局约束

- Chrome Manifest V3，最低 Chrome 116；沿用 storage、activeTab、scripting、sidePanel，不新增 host 权限、后台服务、生产依赖或远程资源。
- 仅当前标签页的已加载可访问文本 DOM；视口外正文可读，隐藏、折叠、导航与操作控件不自动加入正文。不爬取子页，不操作任务勾选状态。不支持图片、canvas、跨域 iframe、封闭 Shadow DOM；明确报告可见边界。
- Key 和模型请求仍仅在扩展侧栏；页面脚本不联网、不读取凭据。原文位置及本地引用校验留在页面会话，不进入提示或持久缓存。
- 用户明确选择的文本/区域是语境硬边界。章节取消后重新准备语境与缓存身份；单纯显示方式/定位变化不改变翻译输入。
- 数据来源与既有 CoE、.build、简繁独立约束不变；真实网页快照留本地，入库回归使用自造结构。
- 本轮工程验证先使用离线合成响应；不重新开启已失败的提示词或模型质量试验。格式合格仍不代表语义准确。

## 1. 范围与结构

默认读取当前页正文，不以残留 Selection 决定默认范围。明确提供整页正文、选中文字、点选区域；空选区明确提示，不回退整页。区域选择有高亮、Esc 取消与超时清理，不触发原站点击。

识别主内容区域及其相邻卡片，不以最长 article 直接代表整页。仅排除站点页眉导航，不排除正文 header；语义标题及明确结构标题形成章节，保留列表与表格关联。重复 DOM 不重复收集，正常重复文字保留。原样保护与确定性词缀路由沿用。

读取成功只预览原文/术语、本地词典和有效缓存，不自动发送请求。预览显示范围、章节、已选段数与文本量；允许取消章节，开始前给出含提示与语境的用量估算。阶段适配器保留阶段选择；切换阶段仅切换待译范围。

超过 5000 块或单块 20000 字继续明确诊断；不能把截断当完成。已选/完成/失败/原样保留各自可见。

## 2. 统一输出接纳

新增独立于语义提示的格式接纳函数。模型原始单段在恢复前检查协议残留、未知/缺失/重复占位；恢复后仍做既有术语/数值等核对。完整段合格才显示，最终请求结束后才缓存；请求截断不缓存受影响结果。

内部 s/t/m/context/quoted-stat 的字面、实体编码及残缺形式不能成为正常译文。源文原有同形标记通过占位恢复，不能简单删除所有 HTML。普通术语/语义警告仍显示“待核对”，格式失败显示原文与原因、允许手动重试，不自动请求。

旧缓存命中必须重新经过格式检查；检查版本进入缓存身份。失败缓存不显示、不计完成、不自动重试、不清除 Key 或其他无关数据。复制与页内呈现仅消费同一合格结果。

## 3. 原文位置与页内呈现

提取时在页面内保留会话编号、原始文本节点边界及引用文本；发送给侧栏的仅是会话编号与块编号。每次定位/显示前验证节点连接、URL、原文引用；变动或歧义时拒绝定位并提示重新读取，绝不靠第一个相同短语猜位置。来自站点 JSON 而无可靠可见 DOM 对应的块明确回退侧栏。

默认页内对照，在原文附近追加扩展独有的 Shadow DOM 容器，不替换原文、不修改原站 innerHTML。表格/代码/交互标签等无法安全插入的位置使用侧栏。定位时短暂高亮原文，兼容最低浏览器；用户能恢复原文。保持原有链接、任务复选框、文字选择与键盘功能。

提取排除扩展自己的节点，重复读取不能把译文当原文。移除时只清理本扩展容器、样式及监听，不恢复整页旧快照。动态变化使锚点无效时清理对应译文；恢复和页面退出释放监听。

## 4. 侧栏、暂停与缓存

侧栏保留章节导航、标题层级、列表/表格的可读关系，每块提供定位原文。显示页内成功/回退或失效状态，切换“原文旁/仅侧栏”只改变显示。

停止、重读、切换范围均取消旧任务，晚到结果不写入新页面或缓存。关闭侧栏中止请求，已完成页内译文可保留；重开读取后复用合格缓存，只由用户开始补未完成段。无隐形后台续费。

## 验收

- 自造多卡片总览包含所有已标注正文及正文 header 标题；无导航/脚本/隐藏复制件误收。用户真实总览至少包含战役、终局、速通、永久奖励及标题。
- 选区/点选区域/取消章节严格隔离语境；整页模式不受残留 Selection 干扰；读取与视图切换请求增量为 0。
- 相同文字多次出现、局部 DOM 替换、SPA 地址变化、旧请求晚到不导致错位或旧写回。
- 字面/编码/残缺协议和未知占位不进入正常展示、复制、缓存；源文同形代码正常保留；缓存与实时路径一致。
- 任务勾选、链接、原站状态不变；恢复原文后无自有翻译节点/样式遗留；再次提取不收自己译文。
- 回归 Mobalytics 阶段、poe2.com、CoE 现有门禁和构建约束。真实包浏览器与离线模拟分开报告，Windows/真实服务未测就明示。

## 交付顺序

先文档与失败样本，再格式/缓存、结构/范围/锚点、双视图与生命周期。各逻辑单元定向验证后本地提交，中间提交不可发布；最后统一升 0.7.0、打包、完整 verify 与独立审查。旧质量周期与其封存材料不改变。
