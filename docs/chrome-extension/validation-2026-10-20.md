# 2026-10-20 CoE 混合语言装备兼容验收

## 版本与环境

- 本地分支 `fix/coe-compat`，基线 `23ce709`；扩展 0.4.2 为未发布候选。CWS、推送、部署、合并及攻略翻译不在本轮范围。
- 最终 ZIP 为 `poe2-extension-0.4.2.zip`，3,309,443 字节，SHA-256 `60eb440d073eb7d107ce6cf8f2f8c1edcca9148acb8bf49114025a40d708f344`。实际浏览器加载的 15 个文件与 ZIP 逐字一致；最终门禁重新构建得到相同哈希。
- Chrome for Testing 151.0.7922.34，WSL/Linux、X11、独立临时配置；目标为 CoE Beta 的 PoE2、English。不是 Windows 安装或真实输入法验收。
- 包含 12,618 条术语、8 项既有来源；只申请 `storage`。新增台服词条仅用于输入反查，显示和中文搜索仍用国服简体，不做繁简互转。本轮 DeepSeek 请求为 0。
- 玩家提供的八件原始文本与完整回放仅在本地保存，不入库；自动回归使用自造最小样本。

## 修复范围与边界

统一识别高级复制中的破碎／打造来源、强化／腐化强化、中文增效、S/J 插槽、分裂状态、传奇双行名称及已核对咒符面板。仅将两条已确认的无引号风味句和一条咒符使用说明作精确分类；其他未知内容继续保留并提示。

导入诊断区分缺项、歧义、格式与对照限制。机制内容完整时允许主动复制；允许转接的装备才开放回填。修改原文后旧结果失效。名称和标签可能保留中文，交易备注和描述不提交，不能把“机制内容已转换”理解成整份文本所有字符都变成英文。

混合输入中的“法杖”对应两服不同类别，不能根据“物品类别”或“物品種類”标题猜选。本轮保留该类别原文并提示使用确认后的英文类别，不借助基底名单决定武器规则。

制作搜索读取当前原站词缀集合，保留词缀中的固定数字；集合缺失时明确提示使用全局候选。Data 组合词缀只在边界清楚且每一段都能唯一匹配时叠加中文；保留原英文节点、关键词和未知子句。

项链的原站 JSON 保存技能词缀原始值 3、品质 40，卡片显示 4；输入只有 Wolf Pack，卡片列出七个技能。转换器没有修改为 4 或补入这七个技能。此处是观察到的 CoE 行为，不据此解释其全部内部规则或归因游戏补丁。

## 工程验证与审查

- 格式／词典阶段：63 文件、717 项针对性测试通过。搜索、复制和组合显示阶段完成相应失败复现与回归；字体缺字按现有离线字体缓存重新生成。
- 独立审查发现三个重要问题：固定数字被占位符混同、跨服同形类别猜选、旧 `knownExplicitHeader` API 契约回归；均已修复，独立复查确认关闭，没有遗留重要发现。授予技能／增效的通用重算提示来自实站验收发现，单独补齐。
- 完整门禁曾发现旧工坊依赖 `knownExplicitHeader` 只接受普通前后缀。已恢复该契约，扩展继续使用通用标题解析；相关三文件 96 项通过，没有扩展冻结工坊的制作能力。
- 最终新增格式／类别／重算回归 30 项通过。全仓检查另发现官网使用说明与新提示不一致，已同步中性提示和对应断言，该文件 22 项通过。
- 第一轮完整门禁退出 1：648 文件通过、3 文件失败；5,758 项通过、3 项失败、1 项既有本地样本缺失跳过，耗时 1,171.22 秒。失败包括官网旧提示、新说明用字的字体覆盖，以及历史 `JewelVaalWorkbench` 的 5 秒时限超时。说明已统一为“机制内容已转换／需先核对”，没有放宽字体检查；三个文件复查共 35 项全过。未改旧工坊、时限、worker 或跳过规则，单次复查通过不代表消除了时限波动。
- 最终 `pnpm verify` 退出 0：651 个测试文件通过，5,761 项通过，1 项既有本地 `.build` 样本缺失跳过；测试耗时 985.94 秒。类型、格式、扩展打包与发布闸门、全仓构建、词典和制作数据检查通过。保留既有 4 项 CSS specificity 警告及历史工坊大 chunk 提示，没有为消除提示改变冻结范围。

运行期间全局包管理器被其他任务更新，与项目固定 pnpm 11.21.0 不一致；自动审批拒绝可能隐式下载的版本检查。本任务随后从已存在的缓存校验并临时解压原版本，通过命令级 PATH 运行门禁，没有下载、全局安装或持久配置变更。
