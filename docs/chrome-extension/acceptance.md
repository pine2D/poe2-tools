## 记录方式

每次验收记扩展 commit／版本、Chrome 版本、CoE 页面与模式、可见站点版本、词典快照、日期。每项标为通过／失败／未测并附复现步骤。使用自造装备，不提交用户真实文本或第三方完整页面。

## 安装与范围

- [ ] 构建目录可通过 Chrome“加载已解压的扩展程序”安装；ZIP 解包后也可安装，入口和词典无缺文件。
- [ ] 权限仅 storage 与 Beta 静态匹配范围；内容脚本不注入旧域名和其他网站，不操作 PoE1。
- [ ] Beta 首页缺少 game 参数、站内切换游戏、原站本地记忆模式分别识别；未知模式不猜。
- [ ] 原站非英文时提示切回 English，不偷偷修改站点语言；用户所述繁体选项不参与简体词典生成。
- [ ] 没有远程代码／词典请求、遥测、剪贴板轮询；原站自身网络行为不误记为扩展上传。

## 显示与原站功能

- [ ] 基底选择、词缀列表、材料菜单、提示框、装备卡、费用历史、Calculator、Simulator、Inventory、Data 主流程分别核对公共文案和游戏术语。
- [ ] 增减词缀、变化数值、切换高级／普通显示、撤销重做后翻译跟随最新结果，不显示旧值。
- [ ] 数值范围、百分号、负号、条件、作用对象、多行分组保留，不因模板匹配吞掉数字。
- [ ] 未命中英文仍可阅读；中英对照可辨认；不以机器繁简转换替代国服术语。
- [ ] 原站按钮、右键菜单、拖拽流程、保存／加载、复制／导出仍可用；存档与数值语义不因翻译变化。
- [ ] 重复挂载、切换页面、popup 开关、多标签页设置更新不重复观察；关闭后移除扩展界面并恢复最新原文。
- [ ] Chrome 管理页禁用／卸载后刷新标签页恢复原站；安装说明区分此操作与扩展内即时关闭，不声称两者生命周期相同。
- [ ] 动态词缀列表中无无限观察循环；记录大列表操作前后响应情况和控制台异常，不预设未经测量的性能结论。

## 搜索

- [ ] 基底、词缀、材料、Data 分别用简体与等价英文检索，候选和选中身份一致。
- [ ] 用真实中文输入法验证组词中不转换；组词完成后候选准确，继续输入和移动光标不丢字。
- [ ] 唯一精确命中可自动提交；多义、别名与部分词有中英候选；无结果保留原输入。
- [ ] 上下键、回车、Escape、点击、清空、粘贴、中英混输、快速连续输入均可用；过期结果不覆盖最新查询。
- [ ] 原站过滤／排序和显示译文共存；报价、备注、项目名称、模拟步骤说明不被当成术语搜索框。
- [ ] 控件结构改变导致适配失败时，该控件回到原站行为，不阻断其他页面操作。

## 装备文本

- [ ] 中文粘贴经过预览后才提交；原文可取回；未知行、歧义、缺范围有定位信息，不静默猜测或删除。
- [ ] 普通／魔法／稀有的基底、物等、数值、前后缀和混合词缀身份与原站导入结果一致。
- [ ] 腰带咒符位的 `2(1-3)`、逆序范围、无等阶词缀分别核对；不把缺等阶当不可翻译。
- [ ] 技能、品质、孔位、符文、破裂、工艺、亵渎、腐化逐结构核对并登记覆盖，不从一种普通法器推广为全部通过。
- [ ] 咒符／传奇可对照，不能因翻译成功声称能制作；原站拒绝导入时保留诊断和英文结果。
- [ ] 默认导入不把原装备或交易备注写入 URL；主动选择 URL 出口时明确展示目标和传递文本。
