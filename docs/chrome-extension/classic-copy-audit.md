# 经典词缀POB复制修复

2026-09-26，0.1.109，Linux Chrome151.0.0.0；CoE Beta／PoE2／English。所有输入为本项目自造样本。

## 扩大覆盖发现的缺口

0.1.108已修复属性面板标签，但首次11组POB复制与独立无扩展基线对比，有8组仍混入中文：法器、鞋、手套、四种戒指和翠玉护身符；该轮稀有弓、普通头盔和普通胸甲本来一致。最初脚本只检查基底名及undefined，记录的PASS只代表该局部断言，不代表完整对照通过；检查原文后发现中文，再补充汉字排除及完整基线比较。

无扩展法器公开DOM同时存在高级.modifier内的.stat及经典.modifier直接文本。经典词缀如“60% increased Energy Shield”没有.stat，原先会被通用显示层局部译成“60% increased 能量护盾”；移动速度与生命等完整短句也会被改写。POB读取经典词缀，故仅保护高级.stat不足。

## 修复与回归

经典.item .modifier加入原文保护范围，用既有Shadow DOM词缀中文层显示。含.stat子节点时不再叠加父级中文，保持高级层逐条展示；modifier／currency用途类变化纳入边界观察。数字、关键词节点、原站textContent和复制语义保留。

单双语回归均先复现原文污染；另外验证数字更新、停用清理和高级／经典结构切换时恰好各一层译文。初版基于:has的去重在动态切换回归中留下父级重复层，改为实时querySelector检查后通过，不将此测试结果泛化为原站或浏览器缺陷。

36文件291项相关测试、类型、全仓Biome1160文件、构建及严格打包检查通过。本轮未重跑全仓verify，最近全仓基线仍为d43f008／0.1.108。
