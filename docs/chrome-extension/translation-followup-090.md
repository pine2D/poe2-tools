# 0.9.0 阅读与 CoE 跟进契约

用户授权：修复条件菜单漏译、调查传奇导入和残留中文，增加可置顶拖动的多个划词气泡，并标注译文中的游戏术语。只做本地提交与候选包，不推送或上架。

## 落地顺序

1. CoE：显式转义换行在展示和检索边界统一规范化，保留原节点、复制文本和搜索属性。四条无官方对应的持续伤害加成用独立 manual 展示词条补齐，可用于中文搜索，但不能反向导入、不能流入攻略官方词缀表。未知来源类别不得猜成某种影响。
2. 译文术语：从本段已确认的源术语映射到中文结果，长词优先，不靠全文字典扫短词；歧义、提示项不伪装为已确认。共用标注与安全渲染，覆盖侧栏、页内和气泡。轻量虚线下划线，悬停或聚焦看英文，复制保持纯译文；链接内不嵌入交互控件。
3. 多气泡：点击翻译或置顶后保留，各自取消、关闭、复制；新选区不取消其他请求。标题可拖动，也可用方向键移动；置顶仅指当前网页内，固定气泡高于普通气泡。上限 6 个，满额时提示关闭一个，不自动丢弃结果；后台既有 4 个并发限制不变。视口调整重新约束位置；页面离开、原文失效清理相关结果。
4. 单元回归、隔离 Chromium 实测、工程门禁、版本与文档、生成并同步本地候选 ZIP。

## 已取得的原因证据（2026-10-21）

- 灌注句子的实际换行可匹配；字面 `\n` 不能匹配，词典已有完整译文。
- 传奇法杖的机制词缀全部能翻译。“法杖”存在国台服类别同形歧义；即使对照样本手动使用正确英文 `Wands`，原站仍返回 `Unsupported rarity`。扩展不绕过稀有度，不改成稀有装备。
- 随机稀有名称、词缀组的名称与标签原样保留是现有转换契约；基底、属性正文、数值和分组结构是主要解析信息。需在原站对照中确认六条词缀，而非单凭中文残留判断成功或失败。

## 验证边界

用合成测试覆盖结构和行为；用户原始装备仅留临时目录，不提交。原站规则、数值与所有网站的兼容性不因本次通过而扩大声明。真实模型质量不属于本轮已证明的结果。工程验收用本地替身，不消耗 DeepSeek API。
