## 真实浏览器检查

环境：本轮专用 Chromium 149、独立配置与虚拟桌面；不接管用户日常浏览器。真实 DeepSeek 请求 **0**，本机合成服务累计 **9** 次请求（含验收调试及一次撤权中止）。只验证交互、协议和生命周期，不据此声称真实模型语义质量通过。

| 场景 | 实际结果 |
|---|---|
| Chrome 原生拒绝/允许 | 拒绝后不保存规则；允许后仅增加选中主机权限，并保存精确来源/目录 |
| 自定义站点 | 新标签自动启用；同主机目录外页面不启用；仅选择文字请求增量 0 |
| 常用预设 | Domistae 升级攻略实际授权后自动启用；选择 322 字符正文出现翻译入口，请求增量 0 |
| 页面关闭划词 | 实际弹窗关闭后，页内 hash 跳转与真实后台停止/重启仍保持关闭；刷新到新文档后按站点规则恢复 |
| 撤销/移除 | 请求进行中撤销 host 权限，气泡与当前文档授权清除，迟到响应不再生成卡片；设置页显示撤权，移除规则后刷新不自动启用 |
| 多气泡操作 | 两个气泡独立存在；置顶/拖动、关闭、纯文本复制通过；复制通过原生 Ctrl+V 核对 |
| 气泡展开 | 420px 浅色、360px 深色，贴底展开原文后标题 top 位移小于 1px，气泡不超出视口 |
| 侧栏 | 360/420px，无横向溢出；范围展开前后触发标题 top 位移小于 1px，设置区域不扩大 sticky 任务栏 |
| 最终构建确认 | 浏览器加载最终 guide 资源，目录默认关闭；用户展开后翻译更新保留展开状态 |

自动注入发生在页面加载完成时；真实页首个自动化选区事件早于脚本注册，没有生成卡片，待页面完成后重新选择即通过。未将“脚本已注入”的提示当成划词成功证据。代码还拒绝来自普通扩展标签页冒充弹窗的控制消息，后台恢复探针对此返回拒绝属预期。

浏览器证据保留在本轮本机临时验收目录，含原生授权截图、两个宽度的侧栏、浅深气泡、站点设置、Domistae 选区及 JSON 结果；不入库第三方网页正文或浏览器配置。任务专用浏览器、虚拟桌面和本机合成服务交付前关闭。
