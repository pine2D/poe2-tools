## 问题与结果

| 原问题 | 处理结果与证据 |
|---|---|
| 待译时复制、重试仍可见 | 图标样式只对非 hidden 按钮生效；空译文也拒绝复制。回归先失败后通过，浏览器中两个按钮均为 `display: none`、不占空间。 |
| 无效限额假保存 | 表单与写入边界使用相同整数范围；错误贴近字段并关联可访问说明。实际输入 500 后不写入，焦点回到错误字段；2500 字符、51 MB 保存值与反馈一致。旧配置读取仍保留容错回退。 |
| 清除 Key 无确认 | 页内确认明确删除 Key、缓存、自定义接口配置与已确认地址，保留站点授权、CoE 开关和限额。初始焦点在取消；Escape 取消并返回触发按钮。实际确认后 Key、接口配置、确认地址为空，限额仍为 2500 / 51。 |
| 长 Base URL 横向溢出 | 网格与字段允许收缩，确认文案可在长域名内部换行。300 / 360 / 420px 视口中，文档宽与滚动宽分别相等（285 / 345 / 405px）。 |
| CoE 状态被误读为整体状态 | 弹窗独立命名“网页翻译”和“CoE 中文显示”；无 CoE 应答显示中性“未连接”，保留具体适用范围与刷新提示。原生弹窗中网页翻译入口同时可用。 |
| 异步操作没有等待与防重复 | 连接、保存、清除即时显示等待文字，操作互斥，失败后恢复按钮。连接测试可取消，迟到响应不覆盖新状态；本机延迟响应及连接失败已验证。 |
| 设置往返失焦 | 进入设置聚焦标题，返回恢复触发入口。首次配置保存后提示会消失，因此焦点交给常驻设置按钮；该路径经实际复现后修正并确认。 |
| 首次说明挤占阅读 | 常驻发送提醒，详细发送范围和本机存储说明按需展开。360px 下说明区约 95px（修正前 158px）；360×800 可见当前原文标题（纵向 771–794px）。关闭说明后焦点落到可用操作。 |
| 高级参数默认铺开 | JSON 参数默认折叠，已有配置时摘要注明“已配置”，保存失败且填有参数时展开以便检查。 |
| 首次 Key 帮助不足 | 增加创建 Key、填写地址与模型、测试再保存的简明步骤，保留本机存储和服务商数据用途说明。帮助按需展开。 |
| 输入及服务选项点击区偏小 | 输入框、服务选项、相关辅助入口均至少 44px；实际几何检查通过，200% 浏览器缩放下仍无横向溢出。 |
| 单站与全部启用争夺层级 | 四个单站直接选择，批量入口收在次级折叠中；原有同步申请权限的用户手势链保留，权限相关回归通过。 |
| 站点管理链接使用浏览器默认颜色 | 统一铜金链接、下划线距离与键盘焦点；滚动条采用现有语义颜色。 |

气泡保留已有结构和配色，没有为本轮整改改写其实现。浅、深宿主页及 360px 宽度下完成译文、复制反馈、置顶、方向键移动、独立关闭检查；可见操作均为 44px，译文字号为 16px。
