# 阅读体验与 CoE 覆盖整改（0.8.0 候选）

2026-10-21，用户批准按顺序实施并本地提交。侧栏选定“目录＋当前段＋异常”；划词选定“侧栏关闭也能独立翻译”。本文是实施契约，完成状态以验收记录为准。前置证据见 `validation-2026-10-21-reading.md`；0.7.0 的旧语义质量结论不变。

## 问题与边界

- CoE 单独运行仍缺分类标签、属性缩写及词缀名称；现有 3706 条模板测试不能代表所有界面类别。截图中的 Marksman/Decay 有原始词缀来源可追溯；原站 influence=undefined 和历史词缀另记，不猜译。
- 总览页已读到 99 段，但失败、原样保留、仅侧栏显示被混成“缺译”。自造合格响应证明用户举例的两段可提取和定位，不能据此推断用户两次真实失败的原因。
- 原文旁模式仍复制整篇到侧栏，99 段有近 300 个操作；阅读焦点、错误恢复、用量位置不清楚。原位黑色大卡片又覆盖了原网页的视觉层次。

## 固定产品行为

1. CoE：本地确定性翻译，不接模型。按 UI 标签、属性、词缀名、完整词缀与动态控件分类维护来源和回归；中文显示不改 value/search/tooltip 数据、复制原文和自定义名称。未知或来源未译保留原文并可诊断；不把保留的专名计为已译。
2. 攻略：翻译状态（未开始/处理中/完成/失败/原样保留）与呈现状态（原文旁/仅侧栏/位置失效）独立。失败可定位并手动重试；回退说明原因；待核对和格式失败区分。不得为减少失败放松术语、数值、协议与缓存接纳。
3. 原文旁模式侧栏只默认展示目录、当前段、异常入口；当前段支持前后切换和定位。章节范围放入折叠设置，不与目录混淆。仅侧栏模式保留完整结构阅读。顶部保留唯一主操作与进度，完成后不能继续显示无意义的开始按钮；用量不藏在文末。
4. 页内译文继承原网页字号、行距、浅深色；只用轻量区别。按真实文本范围选择安全落点，能处理列表内链接、多个独立文本段和卡片；复杂表格、代码、交互结构或失效位置明确回退。保持任务勾选、链接与原文选择，不改写原站 innerHTML，不追踪跨页面。
5. 划词：由扩展弹窗明确启用当前页，选择文本后出现翻译按钮，点击才请求；关闭侧栏仍可工作。支持键盘关闭、取消、复制、失败说明和手动重试。空选区、输入框、密码、编辑器及不可见文本不发送；超长选区明确限制。网页刷新/跨站导航后需重新启用，不常驻所有网站。
6. 共享：侧栏与气泡复用术语、确定性路由、上下文硬边界、缓存键与接纳规则，设置和 Key 仅在扩展侧。模型请求由扩展页或按需 service worker 执行；页面内容脚本不联网、不接收 Key。worker 只接受本扩展顶层内容脚本、已授权标签页及有界请求；不对页面 window 消息开放服务。关闭气泡、断连、导航会取消其请求；后台中断明确失败，不自动续费或重试。侧栏关闭继续取消侧栏自身任务。

- 状态：失败两段可定位，错误与回退分别统计；重试仅发送所选失败段；停止、重读、旧结果晚到不改新页面。

- 原位：列表/链接/连续文本/卡片/浅深页面/表格回退/重复短语/DOM 变化；原站交互和复制不变，重复提取不含本扩展译文。
- 气泡：侧栏关闭、缓存命中、词缀本地命中、接口失败、协议失败、取消、关闭、导航、worker 中断、长/空/敏感控件选区；Key 不进入消息、DOM、日志和产物。
- 真包浏览器与模型语义质量分开报告；未实测平台不宣称通过。保留已知表格、跨域 iframe、封闭 Shadow DOM、canvas 与未加载内容限制。

## 独立划词实施记录

弹窗只查询当前页状态；点击“启用本页划词”后注入隔离脚本，选择文字只出现入口，真实点击才请求。单次最多 6000 字符，保留选区内实体/代码保护位置，不附带页面地址、邻段或标题。侧栏与后台共用请求配置、控制器、词典路由、缓存键和译文接纳；语境不同的相同文字不会强行共用缓存。

新增固定 `background.js` 与 `selection.js`；权限仍为 storage/activeTab/scripting/sidePanel，公开资源和 CoE 固定匹配范围不扩大。后台核对扩展、顶层 frame、标签页与 documentId；启用只接受扩展弹窗。临时授权在 storage.session，导航/关闭后撤销；断连、关闭、取消、超时均终止请求，旧授权和晚到结果不恢复任务。单连接最多一次请求，全局至多 4 个任务、单次 90 秒截止；只在请求期间每 20 秒通信，不维持空闲后台。

Chrome 149 真扩展在无侧栏条件下验证：选择零请求，首次合成服务请求成功，再次相同范围命中缓存，生命词缀本地命中；协议残留被拒绝，只有手动重试新增请求；取消后晚到结果不显示，刷新后重新启用。此单元新增 18 项回归（范围、敏感控件、缓存、取消、授权、超时、纯文本呈现、后台断连及弹窗），并运行现有攻略/权限/包检查；真实模型语义质量不在这组证据内。

实现依据：[Chrome 消息通信](https://developer.chrome.com/docs/extensions/develop/concepts/messaging)（保持 Chrome 116 的异步 `return true` 通道）、[扩展后台生命周期](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle)（可终止后台、有限任务及显式失败）。
