# 隐私与权限

2026-10-20 施工说明：[衔接契约](translation-bridge.md)计划让正文请求携带用户所选范围内的原文语境与局部词缀证据。只发送用户选择范围，不读取范围外正文；独立已知词缀本地翻译。当前未完成集成，以下仍描述 0.5.0 基线；完成后须同步更新本页再交付候选。

## CoE 中文显示（原有功能）

- 内容脚本只匹配 `https://beta.craftofexile.com/*` 的顶层页面；检测到 PoE2 与英文界面后启用。
- 术语 JSON 与注入衬线字体（`assets/serif-sc-l1.woff2`）随扩展打包，运行时读取扩展自身资源；`web_accessible_resources` 只把这两个文件开放给 `https://beta.craftofexile.com/*`。
- 搜索选择与英文装备填入只在当前 CoE 页面操作 DOM；后续原站行为遵循 CoE 自己的隐私政策。扩展不生成携带装备文本的 URL。
- CoE 内容脚本不发网络请求。

## 攻略翻译（0.5.0 起）

- 只有在你点击扩展图标并点“翻译此页”后，扩展才在当前标签页读取一次正文，不改动原页面，读完即止，不留监听。
- 只有在你自己配置了翻译服务（默认 DeepSeek，或你填写的 OpenAI 兼容接口）并开始翻译后，侧边栏才把**选中的段落和本段命中的术语**发给**你选择的那一家服务商**。不发送网址、Cookie、账号信息。侧边栏“设置”里的“测试连接”也会联系所选服务商，只发送一句简短的测试消息，不含攻略文字。服务商如何处理这些文字，以其隐私条款为准。
- **扩展不内置任何 API Key**；Key 由你填写，只保存在本机扩展存储（扩展自己的 IndexedDB），未加密；网页和本扩展注入网页的脚本都读不到。建议为本扩展单独创建 Key 并设置额度上限。
- 译文缓存保存在同一位置，只存原文的哈希、译文与核对结果，不存原文；默认上限 50 MB，超出后删除最久未用的条目。侧边栏“设置”里可以清除缓存或清除全部数据（含 Key）。
- 只有侧边栏页面可以联网；扩展页面的内容安全策略只允许连接 https 地址与本机地址，脚本只能来自扩展自身。

## 权限

- `storage`：保存设置与攻略翻译偏好；不保存装备全文、查询历史或账号信息。
- `activeTab`、`scripting`：在你点击扩展图标后，临时读取当前标签页正文。打开弹窗本身就会授予这个临时权限，弹窗因此能看到当前页网址和标题，但只读取标签页编号与加载状态；跳到其他网站或关闭标签页即失效。拼图菜单里可能出现“Access requested”，扩展不会因此获得常驻网站权限。
- `sidePanel`：在当前标签页右侧显示译文。
- 没有后台服务、统计 SDK、远程脚本、请求拦截或后台剪贴板读取。

## 其他

- 弹窗与侧边栏页脚的“检查更新”只在新标签打开网站介绍页（https://poe2-tools.pine2d.com/extension/）。
- 弹窗打开时只向当前标签页里的中文助手询问本页状态（是否生效、已翻译处数、搜索框是否接上、初始化错误类别），应答中不包含网址、页面文字或装备内容，不发网络请求；“刷新页面”按钮只重新加载当前标签页。
- 来源和快照哈希随词典打包。术语来源见仓库 `docs/data-sources.md`。MIT 仅覆盖自有代码，游戏文本权利归相应权利人，不代表 CoE、Mobalytics、poe2.com 或数据源背书。
- 物品基底与传奇的中文名（约 2000 条）、石板名，以及攻略词典中的宝石与天赋名，取自未明确授权的社区资料（`docs/data-sources.md` 标为灰区）。这些来源可以整体移除，其余术语不受影响，但相应名称的覆盖会减少，依赖基底和传奇名识别的装备导入不可用；不复制 CoE 执行代码、权重或专有汉化扩展数据。
