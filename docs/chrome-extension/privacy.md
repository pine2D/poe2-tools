# 隐私与权限

- 仅匹配 `https://beta.craftofexile.com/*` 的顶层页面；检测到 PoE2 与英文界面后启用。
- 唯一声明权限为 `storage`，只保存启用／中英对照设置。不保存装备全文、查询历史或账号信息。
- 没有后台服务、统计 SDK、远程脚本、请求拦截或后台剪贴板读取。术语 JSON 随扩展打包，运行时读取扩展自身资源。
- 搜索选择与英文装备填入只在当前 CoE 页面操作 DOM；后续原站行为遵循 CoE 自己的隐私政策。扩展不生成携带装备文本的 URL。
- 来源和快照哈希随 `assets/dictionary.json` 打包。术语来源见仓库 `docs/data-sources.md`。MIT 仅覆盖自有代码，游戏文本权利归相应权利人，不代表 CoE 或数据源背书。
- 弹窗页脚的“检查更新”只在新标签打开网站介绍页（https://poe2-tools.pine2d.com/extension/），扩展本身不发任何网络请求。
- 物品基底与传奇的中文名（约 2000 条）及石板名取自未明确授权的社区资料（`docs/data-sources.md` 标为灰区）。这些来源可以整体移除，其余术语不受影响，但基底和传奇名的覆盖会减少，依赖它们识别的装备导入不可用；不复制 CoE 执行代码、权重或专有汉化扩展数据。
