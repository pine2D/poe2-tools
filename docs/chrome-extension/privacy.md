# 隐私与权限

2026-10-21：本地 0.10.0 阅读重构候选，尚未公开发布或更新 CWS。实际验收与限制见[0.10.0 验收](validation-2026-10-21-reading-010.md)。旧语义质量失败结论保持。

## 独立划词

从弹窗临时启用当前页，或在已授权的站点自动启用后，选择文字只出现翻译入口，点击才发送。侧栏可以关闭；单次不超过 6000 字符，仅发送选中文字和同一范围的术语/词缀证据，不附带页面地址或邻段。输入框、密码、可编辑区域、不可见文本及扩展自身内容不作为选区发送，超长选区提示缩小。

划词由扩展内 service worker 执行，复用侧栏的设置、Key、缓存与译文接纳。网页仅传受限选区并接收结果，不获取 Key、不直接联网；后台不向网页开放 window 消息或跨扩展接口。只接受本扩展已启用文档的顶层内容脚本，当前文档授权在 storage.session 暂存标签页、文档编号及自动授权页面地址，用于范围复核；关闭标签页后清理，不永久记录浏览历史，也不保存正文和 Key。刷新、导航或关闭标签页后撤销旧文档授权；已授权的自动站点在新文档重新核查后启用；关闭气泡、取消、断连或 90 秒超时中止请求，不自动恢复或重试。已发送部分仍可能产生服务商用量。

可同时保留最多 6 个气泡，后台全局最多 4 个划词请求；每个请求都须单独点击，拖动、置顶或选择文字不发送请求。关闭一个气泡只取消对应请求，禁用本页划词会取消该页全部请求。译文术语标注完全在本地完成，不增加请求或改变复制内容。

后台仅在已发起的有界请求期间通信，空闲时可被 Chrome 终止；被系统中断时明确显示失败，用户自行重试。基本权限仍为现有四项，新增按用户选择授予的可选 host 权限，无遥测或常驻全站脚本；侧栏自身请求仍在侧栏关闭或隐藏时取消。

## CoE 中文显示（原有功能）

- 内容脚本只匹配 `https://beta.craftofexile.com/*` 的顶层页面；检测到 PoE2 与英文界面后启用。
- 术语 JSON 与注入衬线字体（`assets/serif-sc-l1.woff2`）随扩展打包，运行时读取扩展自身资源；`web_accessible_resources` 只把这两个文件开放给 `https://beta.craftofexile.com/*`。
- 搜索选择与英文装备填入只在当前 CoE 页面操作 DOM；后续原站行为遵循 CoE 自己的隐私政策。扩展不生成携带装备文本的 URL。
- CoE 内容脚本不发网络请求。

## 攻略翻译（0.5.0 起）

- 只有在你点击扩展图标并点“翻译此页”后，扩展才按需读取当前页正文并预览。默认整页正文，选中文字和点选区域须明确选择；空选区不回退全文。读取、选章节和切换阅读位置不发送模型请求。
- 合格译文默认显示在原文旁的扩展容器，也可仅在侧栏阅读。页面内保存原始节点、引用文本和临时会话编号，用于定位与检查原文变化；这些定位数据不发给服务商、不写持久缓存。变化监听仅在本次页面会话中运行，恢复原文或退出页面时移除；不跟随链接抓取子页。只删除扩展自有节点，不替换原站正文或任务状态。
- 只有在你自己配置了翻译服务（默认 DeepSeek，或你填写的 OpenAI 兼容接口）并点击“开始翻译”或单段重试后，侧边栏才把**所选正文、本段命中的术语、完整词缀引用的中英文对应，以及同一选定范围内的少量原文语境**发给**你选择的那一家服务商**。不额外发送当前页面地址、Cookie 或账号信息；正文自身包含的内容属于所选文本。选区不会扩展到范围外，阶段翻译不会借用其他阶段的正文；取消章节后也会重新限定语境；原样保留块不作为模型语境。侧边栏“设置”里的“测试连接”也会联系所选服务商，只发送一句简短的测试消息，不含攻略文字。服务商如何处理这些文字，以其隐私条款为准。
- 完整且无歧义的已知词缀在本地翻译；未收录的明确词缀、歧义、来源未译、代码与截断块原样保留。译文须在请求正常结束且通过格式接纳后才显示和缓存；内部协议残留、异常占位和截断结果被阻断，缓存读取也重新核对。停止、重读或原文失效后旧请求不能追加结果。关闭或隐藏侧栏中止请求，已完成的页内译文可保留；重开后仅复用通过检查的缓存，未完成段须再次点击开始。不自动重试服务请求，逐段重试由用户操作发起。
- **扩展不内置任何 API Key**；Key 由你填写，只保存在本机扩展存储（扩展自己的 IndexedDB），未加密；网页和本扩展注入网页的脚本都读不到。建议为本扩展单独创建 Key 并设置额度上限。
- 译文缓存保存在同一位置，只存包含原文、语境及处理规则依赖的摘要、译文与核对结果，不存原文；默认上限 50 MB，超出后删除最久未用的条目。侧边栏“设置”里可以清除缓存或清除全部数据（含 Key）。
- 发送前按完整提示、术语、语境估算输入，并计入每批输出上限预留；估算不是账单。服务未提供完整用量时保持未知并以收到的文本估算，不将缺字段当作零。
- 只有侧边栏扩展页与划词后台可以向所选服务商联网；扩展页面的内容安全策略只允许连接 https 地址与本机地址，脚本只能来自扩展自身。

## 权限

- `storage`：保存设置、攻略翻译偏好及当前会话的划词授权；不保存装备全文、查询历史或账号信息。
- `activeTab`、`scripting`：在你点击扩展图标后，临时读取当前标签页正文、定位原文并显示或移除本扩展译文。打开弹窗本身就会授予这个临时权限，弹窗因此能看到当前页网址和标题，CoE 状态查询使用标签页编号与加载状态，划词入口另核对当前页面地址与 documentId，仅用于访问控制，不持久保存网址；跳到其他网站或关闭标签页即失效。拼图菜单里可能出现“Access requested”，扩展不会因此获得常驻网站权限。
- `sidePanel`：在当前标签页右侧预览范围、管理翻译与对照阅读。
- 后台负责已授权站点的本地划词激活与用户主动发起的划词翻译；没有统计 SDK、远程脚本、请求拦截或后台剪贴板读取。

## 自动划词站点（0.10.0）

安装时不强制授予全站访问。`optional_host_permissions` 声明 HTTP(S) 可选范围，以支持用户运行时自定义域名；每次 `permissions.request` 只申请用户选中的具体主机。Chrome 的 host 授权覆盖该主机（含端口），扩展再用已保存的精确来源和目录边界限定自动激活；不自动匹配其他子域、相似域名或其他游戏目录，不在 CoE 启用攻略划词。

只在本机保存用户指定的站点规则，不保存浏览历史。常用站点预设需点击授予权限；选择文本只展示入口，点击翻译才调用服务。后台使用授权页面的 URL / documentId 检查范围，按导航、撤权、移除规则清理气泡与请求。未授权页面不注入探测脚本。本页临时关闭保留到文档更新；导航取消且原文档未变时继续关闭。后台重启仍读取会话暂停与规则，不绕过授权。

拒绝授权不保存规则；保存失败或超限时回滚本次新增、且未用于已有规则的权限。站点设置页“移除”会撤回没有其他规则共用的权限；Chrome 管理页撤权后显示“访问权限已撤销”。侧栏“清除全部数据（含 Key）”针对翻译服务与缓存，自动划词站点请在站点设置中移除；不静默替用户扩大或撤销其他网站设置。

Lucide SVG 图标随包提供，不从 CDN 下载，不新增遥测。
