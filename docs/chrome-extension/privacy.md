# 隐私与权限

本说明覆盖扩展当前版本的本地处理、联网边界、本机存储与浏览器权限。当前支持范围见[兼容性记录](compatibility.md)，安装、站点授权和数据清除方法见[安装与使用](install.md)。

## 本地处理（不联网）

- **CoE 中文显示、中文搜索与装备文本转换**完全在你的浏览器内完成，不向任何外部服务器发送请求。
- 内容脚本仅在 `https://beta.craftofexile.com/*` 顶层页面加载，读取随扩展打包的词典与衬线字体；搜索选择和英文装备填入仅操作当前页面输入框，后续行为遵循 CoE 自身隐私政策。
- 弹窗打开时只在本地查询当前页的 CoE 生效状态与划词开关状态，不发网络请求；“检查更新”只是在新标签页打开网站介绍页。

## 何时会发送文字（联网边界）

扩展**不内置任何 API Key**，没有统计 SDK、遥测或远程脚本。仅以下三项主动操作会向你自己在“设置”中所选的服务商（默认 DeepSeek，或你填写的 OpenAI 兼容接口）发送请求：

1. **攻略对照阅读**：点击扩展图标 → “预览此页翻译范围”仅在本地读取并预览当前页已加载的可见正文，不发送网络请求；只有当你点击**“开始翻译”**或**单段重试**时，侧边栏才会把**所选正文、本段命中的术语、完整词缀对照及选定范围内的少量原文语境**发往你所选的服务商，不额外附带页面 URL、Cookie 或账号信息。
2. **独立划词翻译**：临时启用本页划词或在已授权站点选中文字时，只显示翻译入口；只有点击**“翻译选中文字”**后，才发送选中的文字（单次不超过 6000 字符）及相关术语，不附带页面地址或相邻段落。输入框、密码框与可编辑区域不会被读取。
3. **测试连接**：在侧边栏“设置”点击“测试连接”时，仅向所选服务商发送一条简短测试消息，不含攻略或网页内容。

完整且无歧义的已知词缀直接在本地转换，不发送给服务商；点击“停止”、关闭气泡或关闭侧栏会中止后续请求（已发出的部分仍可能产生服务商用量）。服务商如何处理收到的数据，以其服务条款与隐私政策为准。

## 本机保存的数据与清除方法

- **API Key 与自定义接口配置**：保存在本机扩展存储中，**未加密**；普通网页及扩展注入网页的脚本均无法读取。
- **译文缓存**：保存在本机扩展存储中，仅保存缓存摘要、译文与核对标记，不保存原文全文；默认上限 50 MB，超出后按最近最少使用清理。可在侧边栏“设置”中单独“清除缓存”，或点“清除 Key 与翻译数据…”一并删除。
- **站点规则与开关设置**：CoE 开关、翻译限额与自动划词网址规则保存在本机 `storage` 中，不记录浏览历史、查询记录或装备全文。自动划词规则需在“管理自动划词站点”中单独删除。

## 浏览器权限说明

- `storage`：在本机保存开关设置、翻译偏好、站点规则及当前标签页的临时划词状态。
- `activeTab`、`scripting`：仅在你点击扩展图标或启用本页功能后，临时读取当前标签页正文、显示页内译文或划词气泡；关闭标签页或跳转到其他网站后即失效。
- `sidePanel`：在浏览器右侧打开攻略阅读与翻译设置面板。
- **可选网站访问权限**（自动划词）：安装时不申请全站访问权限。仅当你在“管理自动划词站点”中主动开启某个常用站或添加自定义网址时，才向 Chrome 申请对应网站的访问权限；删除该站最后一条规则时会自动撤回该权限。
