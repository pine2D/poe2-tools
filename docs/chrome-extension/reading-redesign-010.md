# 0.10.0 阅读交互重构与自动划词

状态：2026-10-21 已实施并通过本轮交互与当前产品工程门禁；0.10.0 本地候选，未公开发布。工作基线 0.9.0。

## 范围与落地顺序

1. 先核查现行侧栏、气泡和授权链路，完成 Impeccable 两路独立评审；本文件记录设计与权限契约。
2. 增加常用攻略站点预设与自定义网址管理。自动激活划词只获得本地选区能力，用户点击翻译才发请求。每个站点由 Chrome 可选权限授予；无强制全站权限。保留临时“启用/关闭本页”。分别验证来源、路径、导航、撤权和后台恢复，与阅读界面统一交付。
3. 重构侧栏：顶部紧凑任务栏；阅读位置直接双选；范围配置独立区域；目录、当前段和异常分层。主按钮唯一突出，辅助操作使用统一 SVG 图标。原文与译文可对照，结果优先。折叠行有稳定宽度和高度，避免 flex 换行及 sticky 容器高度变化造成跳动。
4. 重构气泡：译文为视觉主体，复制/置顶/关闭为有标签的图标按钮；轻量原文折叠与详情，展开不重定位气泡。保留多气泡、拖动、键盘移动、独立取消与游戏术语标注。
5. 真实 Chromium 验证授权、自动激活、导航及撤销；桌面/窄侧栏、浅深页、长译文、展开/收起与焦点一轮集中视觉检查，修正后确认。独立代码审查、当前产品门禁、0.10.0 候选包、本地 commit。不开启 CWS 发布，不推送。

## 自动划词契约

- 常用预设：Mobalytics /poe-2、Maxroll /poe2、PoE Vault /poe2、用户使用的 Domistae /poe2-leveling。它们是入口预设，不声称全文提取全面适配，也不声称网站热度排名。
- 自定义只接收明确 HTTP(S) 网址，无通配符、账号或密码。保留目录边界，不匹配相似域名和其他游戏目录。界面同时展示生效路径和 Chrome 授权的站点范围。
- 可选 host 声明支持运行时添加域名；实际 request 只包含选中的具体域名。不扩大 CoE 常驻脚本范围，不在 CoE 上启用攻略划词。
- 用户拒绝或撤销权限后不显示“已启用”。删除规则、撤权、退出路径、导航或关闭页签时取消对应后台任务；关闭本页在本次文档保持，刷新后恢复站点设置。Chrome 后台重启不会绕过授权。
- 只保存规则，不保存浏览历史；现有凭据/翻译缓存存储保持原契约。自动激活不会调用 API。

## 设计约束

阅读界面采用 L0 暖中性、系统无衬线、克制铜色重点，不使用金属大按钮。气泡根据宿主页采用浅/深色。统一 Lucide 图标，图标按钮有中文 title、aria-label、焦点环和可读状态反馈。小窗口和触控目标不少于 44px；正文 15–17px，辅助 13px。避免嵌套手风琴；原文展开在固定标题下方，阅读控件不随内容重排位置。
