中文扩展原生导入该三物品备份后导出，与备份完整对象相等；无扩展原站导入相同备份后导出也相等，包括UUID、页名、摆放位置、装备全部字段。

保存后刷新页面再导出，新弓ig字段由null变为0，其他字段均相同。无扩展会话按同样的导入弓→保存到该页→刷新顺序，复现唯一新增弓ig从null到0变化。没有删除字段来冒充完整相等，也未推断ig的业务含义；这项原生归一化与扩展翻译无关。备份恢复无需沿用刷新结果作为期待值，其实际结果保留输入的null。
