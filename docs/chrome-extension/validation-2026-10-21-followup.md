# 0.9.0 CoE 与阅读跟进验收

2026-10-21，依照[跟进契约](translation-followup-090.md)。仅交付本地候选与本地提交，未推送、部署或更新 CWS。

## 原因与修复边界

| 用户反馈 | 证据与处理 |
| --- | --- |
| 元素灌注整句漏译 | 原站节点及 search 属性含字面 `\n`，词典已有对应译文；只在展示匹配及中文检索边界规范化。原始文本、节点和搜索属性保留。真实 CR/LF 进入单行输入会被浏览器吞掉，改用原生集合中的连续片段。 |
| 四条持续伤害加成漏译、UNDEFINED | 当前已登记的官方 PoE2 简体词缀快照无对应来源身份，原站分类也未定义。新增独立 manual 展示模板，类别显示“来源未知”；允许中文搜索，禁止反向导入及流入攻略官方机制投影。原站缺失来源图标仍属上游问题。 |
| 传奇符文法杖导入失败 | 机制词缀可翻译；对照文本手动使用正确类别 Wands 后，原站仍返回 Unsupported rarity。扩展明确说明原站限制，不改稀有度绕过。中文“法杖”存在国台服类别同形歧义，未用全局替换猜测。 |
| 英文预览中残留中文却能导入 | 随机稀有名、词缀组名和标签原样保留是转换契约。用户法器对照在原站成功，基底 Runed Focus、物品等级 46 与六组数值分别为 40、25、48、18、31、13；不把任意中文残留都视为安全。 |
| 多个可固定、移动的气泡 | 各气泡独立请求、取消与关闭；最多 6 个，后台全局最多 4 个划词请求。置顶仅表示本网页内高于其他译文气泡，标题支持拖动/方向键。原文或地址失效清理，不保留陈旧结果。 |
| 译文术语可辨识 | 仅使用本段已确认的源术语映射，长词优先、每词首次标注、同译名歧义保守跳过。侧栏、页内、气泡共用轻量虚线下划线；悬停看英文，键盘聚焦展开英文；复制保持纯译文。 |

## 实际浏览器

隔离的 Linux/WSL Chromium 149，加载本轮构建，仅启用本扩展。未改用户日常 Chrome 或其扩展配置。

- 用户手套详情页：120 个菜单行中有 116 个词缀文本节点，全部状态为 translated；其中四条持续伤害已显示对应中文，来源均显示“来源未知”。
- 用户法器详情页：76 个菜单行中有 71 个词缀文本节点，全部状态为 translated；含原文 `\n` 的元素灌注句正确显示整句中文。行数与词缀节点数不同，不用菜单总行数冒充词缀覆盖分母。
- 两页分别输入“冰霜持续伤害”和“收集元素灌注”，选择中文候选后，原站分别筛出 1 项；全部菜单 search/value 属性与操作前相同。该证据限于这两页当前菜单，不声称全站或全部制作池覆盖。
- 无侧栏时先选择文字，新增请求 0；依次点击两个气泡，二者同时处于翻译中并分别成功，新增 2 次本机请求。置顶气泡高于普通气泡，实际拖动后位置改变；关闭第二个，第一个仍存在。原文删除后对应气泡清理。
- 气泡浅色 420 像素、深色 360 像素均留在视口内；关闭重开相同范围命中缓存。实际点击复制后用原生 Ctrl+V 粘贴，内容与纯译文逐字相同，不含英文提示或标注代码。
- 本地三块阅读样本：侧栏与原文旁的瘟疫/能量护盾标注一致；切换阅读位置新增请求 0。标题的合成结果虽然含“能量护盾”，源标题未确认该术语，所以不标注。实际 Tab/Shift+Tab 聚焦后出现英文提示。
- 本轮真实翻译 API **0**；本机合成服务共 **7** 次请求，包含旧测试资料的中断尝试与新资料的复制验收重跑。合成响应只证明工程行为，不代表机器翻译质量改善或通过。

测试曾遇到旧临时资料加载的后台脚本与磁盘构建不一致；重载后 Chromium 进程发生 SIGSEGV，未将失败记录删除或当作产品通过。最终使用全新临时资料完成并发验收。首轮剪贴板 readText 被浏览器权限拒绝，改用真实 Ctrl+V 粘贴验收，没有增加扩展权限。未验证 Windows 最终安装、系统置顶、读屏及真实模型端到端。

CoE 来源：[Beta PoE2](https://beta.craftofexile.com/?game=poe2&language=us)，使用用户提供的两件装备详情。原始装备、页面快照、合成请求与截图仅保留在本机临时证据目录，不提交用户原文或 Key。
