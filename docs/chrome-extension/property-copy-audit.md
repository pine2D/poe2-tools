# 装备属性显示与POB复制修复

2026-09-26，0.1.108；CoE Beta／PoE2／English，独立Linux Chrome最终ZIP实装。

## 实际故障

0.1.107自造魔法火弓，原站POB按钮复制的文本出现“暴击 几率：5.00%: undefined”和“每秒攻击次数：1.20: undefined”。通过popup停用扩展后，相同操作输出“Critical Hit Chance: 5.00%”及“Attacks per Second: 1.20”。不是原站固定格式缺陷，而是翻译替换了原站复制动作依赖的属性文本。原生JSON Export不受该问题影响，不能以此前JSON相等推断POB文本也正常。

## 修复

.item .property加入保留英文的叠加显示区域，沿用独立Shadow DOM中文层。逐文本节点使用现有属性词条及词典，按属性块组合数值；不改原节点、关键词身份或事件。原站textContent不含中文层，未知文本保留英文。单双语设置下该区域均保留英文并附中文，与词缀显示一致，安装说明同步更新。

新增先失败的回归验证原站文本不被改写、中文可见、关键词身份、数字更新及停用清理。原先直接替换属性文字的测试改为检查中文层，同时继续断言英文、数值、范围、用户名称和关键词节点保留。35文件289项相关测试、类型检查、全仓Biome1158文件、构建和严格包检查通过。
