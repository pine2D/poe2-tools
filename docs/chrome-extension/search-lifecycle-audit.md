# 中文查询清空与导航验收（2026-09-26）

使用此前已核对的0.1.95最终解包目录，独立Chrome会话打开新版CoE的PoE2／English。本轮只通过公开控件执行填入、键盘、清空按钮及导航，不读取原站内部状态。本轮无运行代码变更。

| 路径 | 操作与实际结果 |
| --- | --- |
| 制作基底 | 输入“神庙石板”并Enter，等待原生结果卡制作按钮出现；点击 `#searchItemInput .empty` 后，查询值、原生结果区和中文查询提示均为空。 |
| 制作再次查询 | 输入“符文法器”并Enter，查询值为Runed Focus，出现符文法器及符文符文法器两张原生结果卡。没有擅自按词典精确匹配裁掉原站部分匹配结果。 |
| 制作→Data | 点击“数据”，等待真实物品输入框及扩展用途标签准备好，再进行查询；未使用刚出现但尚未完成适配的节点作为最终状态。 |
| Data物品清空 | “崇高石”Enter提交Exalted Orb；原生清空按钮使查询值为空，中文查询提示撤销。 |
| Data再次查询 | 随后“神庙石板”Enter提交Temple Tablet，原生结果区显示神庙石板。 |
| Data物品→词缀 | 切到词缀模式，输入“闪电抗性”，ArrowDown再Enter选择候选，提交#% to Lightning Resistance；提示显示此次映射。原生清空后值为空且提示消失。 |
| 取消候选 | 再输入“闪电抗性”并Escape，原中文输入保留，候选撤销，焦点仍在词缀输入框；Escape没有被误当提交或清空。 |
| 未知输入 | 输入“不存在的测试词”，保持原文，显示未找到术语说明，候选按钮数量为0。 |
| 未知词后切换模式 | 切回物品模式，未知词提示消失；物品输入仍为此前Temple Tablet，保留原站各模式自己的查询状态。 |
| Data→制作 | 点击“制作”并等待基底输入框，查询值为空，没有旧中文候选或提示残留。 |

上述输入由自动化真实键盘事件与浏览器填入完成，未使用Windows输入法，不新增IME验收声明。Data词缀本轮只核对提交值、提示与清理，没有另做其全部结果列表和英文独立会话对照；其他轮的独立对照仍见compatibility.md。价格页、条件搜索及所有语言组合不属于本轮覆盖，不能由这张表推定全部通过。
