# 0.10.1 侧栏紧凑布局验收（2026-10-22）

## 范围与结果

本轮按用户要求提高侧栏信息密度，延续未发布的 0.10.1 本地候选。只修改攻略阅读面板与章节选择；保留双语次序、正文译文 17px / 1.85、标题层级和至少 44px 点击区。不新增生产依赖，不涉及真实模型语义验收。

- 任务栏保留吸顶；进度文字和进度条同行。
- 阅读位置、翻译范围、目录组成一个工具区。360px 及以下阅读位置独立一行，范围与目录并排。后两者互斥展开，面板在文档流内占满宽度。
- 章节数量、全选、全不选同行，取消章节之间额外空白；重名章节使用足以区分的最近父路径，父级也重名时向上展开。完整路径保留在悬停提示与读屏描述。
- 每段工具入口移到原文右侧，展开后显示来源、定位、复制和重译。失败、待核对、保留原文及位置异常继续常驻。
- 页边距 16→12px，组间距 16→8px，段落上下留白 16→12px，段内间距 12→8px。位置统计与异常、恢复原文与用量入口分别合行。
- 范围、目录、段落工具支持 Escape 收回并恢复入口焦点；目录跳转自动收回，正文按吸顶栏实际高度避让。

## 浏览器验证

完成一批验收与一次修正确认，使用最终 ZIP 解压副本，未调用外部翻译服务。

- 320 / 420 / 720px 无整页横向溢出；表格保留局部横向滚动（320px 视口内，容器 281px、内容 541px）。最终 320 / 420px 可见按钮、摘要与章节标签均未小于 44px。
- 420px 浏览器缩放 200% 后，`innerWidth=210`、`devicePixelRatio=2`，文档宽与滚动宽均 202px。主操作、重读、设置仍同排，位置统计按完整信息项换行。
- 范围与目录互斥展开；Escape 关闭并还焦点；目录跳转至正文，焦点位置紧随吸顶任务栏。
- 段落工具在文档流内全宽展开，Escape 收回后焦点回到工具按钮。零选择仍显示“先选择章节／尚未选择正文”，目录入口隐藏，选择面板保持打开。
- 原文旁模式仍只显示当前段，工具默认展开，前后段导航可用；切换回侧栏连续阅读不触发额外请求。
- 重名章节采用短父路径，完整路径在提示和可访问描述中保留；最短父路径不足以区分的情形有单元回归。
- 共 6 次本机合成翻译请求，均发生在建立修改前样本时；之后读取缓存与操作界面未增加请求。最终控制台 0 错误、0 警告。

首轮发现窄屏统计文字被拆词、章节重复显示根路径，已在唯一修正轮处理，并用最终包确认。
