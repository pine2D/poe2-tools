## 发现与修复

0.4.0 的可见装备卡原生 Paste 输出中，高级词缀标题的标签为 `— 属性`；关闭汉化后为 `— Attribute`，PoB 文本不一致。JSON 正确不能证明文本复制正确。

根因：`.item .modifierDetails .tags` 被普通文本翻译层直接改写。0.4.1 把整个高级词缀标题纳入既有独立中文叠加层；保留英文节点、标签、词缀名称、数值与身份。中文兼容原站 `Modifier` 大写与历史 `modifier` 小写。最小回归先在单语、双语两种模式失败，修复后通过；动态更新、未知标签、移除区域与停用清理继续覆盖。

## 后续重复检查

按一条流程复验：安装最终包并核对版本 → 中文搜索并选择候选 → 打开原站导入 → 粘贴上述自造中文样本 → 预览核对 → 主动填入 → 手动继续 → 当前可见装备卡的 JSON 与 PoB 复制 → 关闭汉化后重复复制 → 英文直接导入对照。

另加一个未知行检查：预览后编辑使旧结果失效，再预览应禁止填入，并能定位未知行。比较原站稳定结果；复制输出按完整字节比较，不只检查有没有中文。使用实际剪贴板回贴，避免误选隐藏卡或读到上一次复制内容。关键结构保护由 `modifier-details-copy.test.ts`、`classic-modifiers.test.ts` 与 `property-copy.test.ts` 持续回归。
