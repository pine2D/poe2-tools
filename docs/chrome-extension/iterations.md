# 扩展持续迭代记录

目标：在新版 CoE 的 PoE2 页面持续完善简体显示、中文输入与装备转换体验；旧自研制作网站维持搁置。完成某轮不等于完整兼容性验收通过，范围以 compatibility.md 为准。

## 2026-09-25

- 工具准备：项目级 frontend-design / webapp-testing；来源、许可和安装边界见 development-skills.md。
- 第一轮：完善中文搜索候选的键盘起点、Escape 焦点回归和候选展示。先用可复现测试验证现有缺陷；不改变英文原站查询或自动猜测身份。
- 第二轮：改善 popup 的设置状态和错误恢复，确保“开关已保存”与“当前页面适用”不混为一谈；保持最小权限。
- 后续轮次：排查观察器／导航超时，补齐 Data 词缀、魔法装备、复制导出和真实 IME 验收，再按证据扩展词典与装备覆盖。尚未找到材料独立搜索控件时不猜测接入。

每轮记录实际变更、失败用例与回归、浏览器证据、剩余问题和 commit；不复用上一轮测试结果证明新的行为。

### 0.1.1：搜索与设置反馈

- 搜索缺陷先复现为 3 项失败用例，再修复方向键起点、Escape 焦点回归和唯一精确候选 Enter；输入法合成事件不触发选择。
- 设置缺陷先复现为 2 项失败用例，再加入保存期间锁定、失败恢复、重试和停用时禁用对照开关。没有新增权限或依赖。
- 面板设计：深蓝灰 #192330、正文 #e7ebf0、辅助文字 #b3c0cf、金色 #e4c78a、分隔 #42566d、焦点 #a7d7fa；使用系统中文字体。左对齐单列，顶部标题、两项设置、状态、使用前提。审查后删去额外装饰，保留金色标题与使用前提边线，强调游戏工具身份。
- 自动验证：扩展与 l10n-core 9 文件 48 项测试通过；两包类型检查、扩展构建、最小权限／资源检查通过。未重跑旧做装网站的完整慢测试，不据此宣称全仓 verify 通过。
- 浏览器：首次导航等待超时，随后正常读取页面并切至 PoE2。实装本轮代码后，输入“符文法器”按 Enter 得到 Runed Focus 查询及中文提示；打开扩展 popup 后关闭开关，状态为“已保存，简体中文已关闭”、对照开关 disabled，本机 storage.enabled=false。面板截图已审阅。该会话启动时 manifest 仍为 0.1.0，随后版本号更新并重新打包；内容脚本与 popup 逻辑相同。最终 0.1.1 ZIP 的重新加载和完整导航／真实 IME 验收仍待做。
- 构建环境：改版本后 pnpm 包装命令触发依赖状态检查，因沙箱无法打开包缓存数据库而失败；直接调用仓库相同 build/check/package 脚本成功，无新增依赖。

- 55项测试及类型／格式／构建／包检查通过。最终 ZIP 实装显示68行中52行译文，结果详情点击正常；同时纠正上一轮把短暂空态误当作筛选前提的记录。

### 0.1.4：导入预览有效期

- 三项失败用例先复现：重复预览的旧按钮仍可填入、停用后旧按钮仍可修改原站、编辑原文后按钮未立即禁用。
