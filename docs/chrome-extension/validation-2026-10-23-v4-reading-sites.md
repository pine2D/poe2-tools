# v4 第二批：阅读侧栏、设置与站点验收

2026-10-23，`feat/v4-ui-migration`，承接第一批 `5bbb7a3`。本批迁移阅读侧栏、翻译设置和自动划词站点管理，扩展 0.11.0 仍为本地候选；公开版保持 0.10.1。CoE 自有浮层与网站布局继续留在后续批次。

本轮全部翻译与连接测试使用本机合成响应，没有调用真实服务。工程通过不代表译文准确性通过；既有整段语义质量失败结论不变。

## 实现边界

- 固定标签和按钮采用独立衬线字体，工具界面使用直角、钢蓝主操作、章节分隔与标签格；任意攻略标题、章节、正文和站点名继续使用无衬线。侧栏译文正文保持 17px／1.85。
- 章节选择与自定义接口发送确认使用原生 checkbox，加方形外观；不把选择语义改成 switch。按钮和可点击标签至少 44px。
- 站点列表固定显示四个常用站，另外列出自定义网址；开启、重新启用、删除各有明确入口。删除先行内确认，默认聚焦取消，Escape 保留规则并恢复触发焦点。
- 删除时重新读取规则：同主机其他端口或目录仍使用权限时保留 Chrome 授权；最后一条才撤权。存储失败不撤权，撤权失败单独提示；父子目录重叠时提示其他规则覆盖的范围仍可生效。
- 服务／限额草稿、范围选择、阅读位置、缓存与请求协议沿用现有实现；站点操作完成后保留用户已经移开的焦点和仍在编辑的网址。
- 侧栏和站点只加载 `serif-sc-guide.woff2`：255 字、69,740 字节，预算 98,304 字节；弹窗 44,888 字节、L1 104,228 字节及网站字体分片未变。生成器、许可白名单和扩展打包检查共同约束入口及体积。

站点采用“开启／删除”而未新增暂停开关：现有存储没有独立暂停状态，若以后需要暂停，须先定义规则保留与权限去留的语义。
