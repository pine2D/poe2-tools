# CoE 长装备文本行定位修复（2026-11-15）

本地候选为扩展 0.11.1，修复点击诊断行号后选区仍藏在输入框可视范围外的问题。当前公开版仍为 0.11.0；本轮未提交、推送或发布。既有构筑 A 改动保留，见 [A 实施记录](../validation-2026-11-15-build-delivery-a.md)。

## 复现与修复

使用已发布的 0.11.0 ZIP，在隔离的 Linux Chrome for Testing 156.0.8078.4 中访问真实 `https://beta.craftofexile.com/?game=poe2`。测试文本为自造法器样本，追加连续空行及一条未知文本。点击“第 48 行”后，原文选区为 139–150，选中的内容正确，但输入框 `scrollTop=0`、`clientHeight=346`、`scrollHeight=884`，目标行不可见。浏览器回归在修复前明确失败。

根因是原有处理只执行 `setSelectionRange`，并滚动下方只读预览列表，没有滚动原站输入框。修复在选区建立后，按输入框的实际字体、可用宽度、内边距与折行规则测量选区高度，再滚入视野：短选区居中，超过输入框高度的整行从开头显示。临时测量节点随即移除，不改原文、选区、输入框样式或转换规则；过期预览和已关闭对话框仍受既有保护。

未新增浏览器权限、依赖、数据源或制作准入规则；没有接入原站拒绝识别或自动回退。待核对内容仍阻止填入，最终导入由用户在原站确认。

候选包实际加载版本已通过扩展运行时核对为 0.11.1。以下每个场景均检查 1440×1000 与 390×1000 两个视口，共 12 组通过：
