# 安装与使用

扩展面向新版 `https://beta.craftofexile.com/` 的 PoE2、English 模式。并非 CoE 官方扩展，不覆盖旧版 www 站、PoE1 或所有英文段落。

本地 0.7.0 阅读候选仍未通过攻略整段语义验收，仅供测试；具体通过与未测范围见[阅读体验验收](validation-2026-10-21-reading.md)，不能据此认为网站或商店已有新版。

## 普通用户安装

0.2.0 起不需要自己构建：按[网站介绍页](https://poe2-tools.pine2d.com/extension/)下载 zip，解压到固定文件夹，在 `chrome://extensions` 打开“开发者模式”，点“加载已解压的扩展程序”选择该文件夹。开发者模式需要一直开着；Chrome 会提示扩展不是来自应用商店。同一个 zip 也在 GitHub Releases（tag `ext-v<版本>`）存档。

## 从源码构建（开发者）

仓库根目录运行：

```sh
pnpm install --frozen-lockfile
pnpm extension:package
```

产物是 `apps/poe2-extension/dist/`（可直接“加载已解压的扩展程序”）与 `apps/poe2-extension/artifacts/poe2-extension-<版本>.zip`。zip 只存储不压缩，条目顺序与时间固定，同一份源码打出的 SHA-256 相同；`pnpm extension:release-check` 核对它与入库的 `release.json` 一致。发版步骤见 [README](README.md#发版步骤)。Chrome 不能把这个 ZIP 当商店安装包直接安装。

## 启用与设置

进入 CoE Beta，选择 **POE 2 → English**，刷新页面。点扩展图标打开弹窗：弹窗顶部先显示当前标签页的状态（生效中、部分生效，或未生效及原因），下面一句写明该怎么做；部分生效与初始化失败时可以直接点“刷新页面”。状态下方是“启用简体中文”和“显示中英对照”两个开关，设置保存在本机，不同步账号。若开关下方提示“无法读取设置，请重试。”，点“重试读取”；读取成功前开关保持禁用，不会用默认值覆盖已有偏好。

原站处于非英文的 PoE2 模式时，启用中的扩展会在左下角提示切换 English；可关闭提示，扩展不会代你更改原站语言。

## 与其他翻译扩展同时使用

CoE 页应只由一个扩展翻译。已在 0.6.0 与 PoE2“说”中文 0.5.5.3 的受控对照中复现：后者开启 CoE 翻译时，会把原句局部改成 `Adds # to # 冰霜 damage to Attacks` 一类混排，本扩展无法继续匹配完整词缀。

遇到这种情况，打开 PoE2“说”中文的设置，在“基本设置 & 导航”关闭 `CraftofExile / CraftofExile2` 对应的站点开关，再刷新 CoE 标签页。其他网站开关可保留。只切换本扩展的“显示中英对照”不能恢复已经被另一扩展改写的原文。复现范围及限制见[扩展共存追查](validation-2026-10-20-extension-conflict.md)。

## 攻略阅读（0.7.0 本地候选）

1. 在攻略页点击扩展图标 → “翻译此页”。默认只读取并预览当前页正文，不因残留选区缩小范围。
2. 在侧栏选择“整页正文／选中文字／点选区域”。区域选择先高亮，点击确认，Esc 取消；30 秒内未确认自动退出。仅处理当前已加载且可访问的正文，不包含隐藏、折叠内容或链接子页。
3. 展开“章节范围”取消不需要的章节，核对原文、已选段数和用量估算。配置服务后，点击“开始翻译”才发送请求。切换 Mobalytics 阶段也只预览。
4. 默认在原文旁对照；可切到“仅侧栏”，或点每段“定位原文”。侧栏保留标题、列表和表格结构。没有可靠原文位置或不适合插入的位置明确使用侧栏。
5. “停止”中止后续请求；“恢复原文”移除本扩展的页内译文，侧栏已完成内容仍可查看。原文变化会提示重新读取；重新打开可复用合格缓存，不自动补发请求。关闭或隐藏侧栏也会停止请求。

译文仍须核对游戏术语和动作含义。格式检查通过不等于翻译准确；格式失败保留原文，只能由你明确重试。

## 三个入口

- **显示**：已收录界面与术语增量翻译，含受支持控件的提示和无障碍名称；未命中或多种冲突译文保留英文。0.4.3 起，关闭“显示中英对照”时，制作页及 Data 已识别的装备属性、高级和经典词缀只显示中文，悬停译文可查看原句；开启后同时显示原文及原站英文关键词节点。原始英文节点始终保留给原站筛选和 PoB 复制。双语词缀表的数值表头分行，词缀区空间不足时前后缀表上下排列。国服译名独立取自已登记来源，不做繁简互转。
- **搜索**：在首页基底搜索、制作页词缀搜索、Data 物品／词缀、自定义价格的材料搜索框及制作页计算／模拟器条件下拉框输入中文，选择带英文的候选后执行原站查询。支持中英混输和方向键；唯一精确匹配可在输入框直接按 Enter，其余需选择候选；Escape 关闭候选并返回输入框；离开后重新聚焦仍含中文的搜索框，会恢复候选，不自动提交。选中后的英文值可继续编辑。制作词缀与计算／模拟器条件框按当前原站集合筛选候选；制作集合缺失时明确提示改用全局词典候选。条件框只展示其当前选项中已有的词缀／条件候选，方向键保留输入焦点；提交英文查询后，仍须在原站结果中选择具体条件。自定义价格页按材料名称提供候选；价格数值、未核实的材料下拉框、流程名称和备注不改写。
- **装备文本**：点击原站“导入装备”，粘贴 Ctrl+Alt+C 文本，再点击“预览中文转换”。预览后面板先给一行结论：“可以填入”或“需先核对 N 行”（有涉及整件装备、定位不到行的问题时为“需先核对 N 处”；传奇、咒符为“仅供对照”）；下面按“已完成”“待核对”“下一步”列出，下一步注明由你还是由原站动手。核对原文与英文两栏（窄窗口自动上下排列）；待核对的问题可点击“第 N 行”选中原导入框的问题行，修改后重新预览。机制行完整识别时可“复制英文装备文本”（名称与标签可能保留原文）；允许转接的装备还可“填入英文到原站导入框”，最后自己点击原站 Proceed。填入不等于导入成功，结果由 CoE 确认。交易备注、说明文本留在原文预览，不提交。

装备转换不再限制为11种基底。词典能确定基底和属性英文、字段与分组能准确表达时即可回填；保留数字、原文范围、等阶及多行词缀结构。没有等阶或范围时不虚构补齐，同一英文对应多个词缀ID也不再阻止翻译。装备合法性、词缀归属和数量由CoE判断。

输入同时使用独立国服、台服词典，不做繁简转换；界面与搜索仍采用国服简体。类别按字段核对，“法杖”等两服同形异义项保留原文并提示确认英文类别，不由整件标题猜选。类别译名覆盖盾牌、箭袋、弩及单手／双手武器等已收录类别；补齐护甲、闪避值和格挡几率字段。支持类别／稀有度标题的全角冒号。格式明确的英文催化品质行可原样保留，国服中文催化描述符尚未确证，仍提示而不猜译。

未知关键内容、真实译文歧义和损坏数值仍提示并保留原文。已支持破碎／打造来源、强化与腐化强化标题、中文增效、S/J 插槽、Split 状态和已核对咒符面板。未知特殊标题、未收录类别或属性格式仍可能无法转换；这不是所有装备格式已完成支持。咒符和传奇仅供对照。

已知原站兼容性问题单独警告：环锁腰带咒符位可能被拒绝或丢失，授予技能的等级／列表可能被重算，增效可能被再次应用（已见项链 +3 显示为 +4）。请保留原值，不删行绕过；填入英文之后仍由你点击原站继续，并核对基底、物等、稀有度、数值、范围、等阶与技能。翻译完成不保证原站接受或导入结果完全一致。

## 关闭与更新

从扩展弹窗关闭汉化时，页面立即恢复当前原文并撤下扩展入口。从 Chrome 管理页禁用／卸载时，请刷新已有标签页；浏览器终止扩展后，旧内容脚本无法保证主动清理。

0.5.0 起扩展身份固定。从 0.4.x 升级时，请先在扩展管理页移除旧版，再加载新版；CoE 里的开关会恢复默认，需要重新设置一次。之后的版本照下面的步骤原地更新。

更新时沿用原安装目录与扩展条目：

1. 从网站下载新版 zip（开发者也可重新构建），解压覆盖到原目录；弹窗页脚的“检查更新”会打开网站介绍页，可对比版本。
2. 在`chrome://extensions/`确认“开发者模式”已开启，再点击该扩展的“重新加载”。
3. 核对管理页版本号，重新打开扩展弹窗，并刷新已有CoE标签页。

同目录从0.1.60升级到0.1.61已实测保留启用与双语偏好。重新加载可能关闭已打开的扩展弹窗；旧CoE标签仍需刷新，不能用残留译文判断新版已生效。命令行曾成功加载扩展，也不代表管理页开发者模式已经开启。

上游界面改版若导致入口消失，先关闭扩展核对原站，再提供页面路径和出错动作；无需发送私人装备全文。

## 数据开关

只想在本机看关闭 gray 数据的效果时运行：

```sh
node apps/poe2-extension/scripts/build.mjs --no-gray
pnpm extension:check
```

然后加载 `apps/poe2-extension/dist/`。关闭后基底／传奇名覆盖会减少，依赖其识别的装备导入也不可用。不要接着运行 `package.mjs`：它会用另一份内容覆盖 `artifacts/` 里同版本的 zip，网站构建与 `pnpm extension:release-check` 随之失败；误跑后运行 `pnpm extension:package` 恢复。长期下线按 [README](README.md#下线-gray-来源) 的步骤发版。

此开关按词典表的来源等级移除数据，不是“仅使用官方译文”模式。自写界面标签、完整用途说明和手工别名仍保留，其中部分术语曾参考社区资料，来源见 `docs/data-sources.md`。0.1.70 实测从6916条降为4928条，移除1988条gray词条；这些数字仅对应当前快照。关闭后输入缺失的中文基底名会显示未找到术语提示，不自动猜译。

### 打包前的词典校验

`extension:check` 和 ZIP 打包入口会用浏览器同一套 `createLexicon` 校验实际产物词典，包括身份、来源、数字模板及数值顺序。无效词典会阻止打包，不以资源文件存在代替可加载性。检查时利用已有 Vite 在 Node 进程内编译核心，不写入扩展目录，也不增加浏览器权限或依赖。该检查不能代替完整测试与实站验收。


## 导入已有模拟流程

单个 CoE 流程 JSON：选择“流程模拟 → 新建模拟流程 → 导入一个流程”，粘贴后继续。“载入 → 全部导入”用于原站批量导出数据；单个流程放到这里会被拒绝，按提示改用单流程入口即可。装备高级文本仍走“导入装备”，与流程 JSON 分开。


## 保存与恢复流程

在流程图点击“保存”，填写名称后再次保存。流程名称属于用户内容，即使包含游戏英文术语也保持原样。

在“载入”列表中，点击目标行的“载入”按钮进入该流程；单击名称不会载入。已经是当前流程的行显示“当前流程”，可点击“返回流程图”。刷新后的当前流程与保存列表是两个不同状态。

备份使用“载入 → 全部导出”。恢复使用“全部导入”，原站会提示替换当前数据且无法撤销；不想继续时关闭确认框。恢复保存列表后仍需使用目标行的“载入”按钮，不应假定备份中的当前编辑流程已自动恢复。此流程以一个自造保存项验证，多项和跨游戏备份仍待验收。



## 自制图标维护

`apps/poe2-extension/public/icons/`保存16、32、48、128像素的原创PNG，自有MIT许可适用，图形是设计语言母题的 gem 符号（核心菱环 + 扩展青宝石）。构建直接复制入库PNG。仅在母题或配色改变时重新生成：运行`CHROME_PATH=<本机 Chrome> node apps/poe2-extension/scripts/generate-icons.mjs`，四个尺寸各自渲染，不需要 Python，也不新增依赖。生成后把四个文件的 SHA-256 更新到`docs/data-sources.md`的“素材白名单（第 3 类）”，否则包检查会拒绝。生成器不使用外部字体或图片，未进入扩展包。


条件组的“与／或／非”与“组内匹配数量”是两个独立设置。不要仅凭选择“或（OR）”就认定数量已为1；需要1时在数量框实际输入1、离开输入框并应用更改。本轮实测可保存；自动化验收应检查原生导出中的matches，不能只检查输入框显示值。

预兆用途说明：已核对的42条说明在原文下方显示中文对照，保留原文关键词节点；未知整句保留英文。该说明翻译不代表相应制作机制已经由扩展验证。

渎灵术语沿国服0.5.5官方交易词缀核对。旧称“亵渎”保留为相关界面词的检索别名，仍需选择候选；不改写用户粘贴的原始装备文本。

条件数值编辑：输入后移开焦点，稍候再点击“应用更改”，并重新打开核对。本轮以失焦后等待一秒验证普通等阶2与渎灵前缀数值1均保存；连续快速输入并立即应用曾导出旧值或null，一秒是本次验证间隔，不代表原站承诺的固定时限。重要流程可再导出检查相应tier字段。


已识别的搜索框缺少原生名称时，扩展会补充用途名称供辅助技术识别；有原生关联标签或名称时优先保留。支持随中英对照开关切换，停用扩展后撤下。当前已实测Data物品与词缀搜索的浏览器可访问树，读屏软件仍待验收。

预览结果、原文变化与英文回填会更新简短状态区，供辅助技术读取；装备两栏仍可手动浏览。修改原文后请重新预览，旧结果不能继续填入或复制。

关闭装备导入窗口会撤下中文预览；重新打开后请重新粘贴并预览。

流程模拟侧栏的“查看使用说明”会打开新版教程。六个章节支持中文与双语；原站动图内的英文保持。教程中的“调试”按原文保留尚未推出标记，条件配置段的原文问题另有校注。

## 回填后恢复中文原文

点击“填入英文到原站导入框”后，可用“恢复粘贴原文”恢复本次粘贴的完整文本（含备注），修改后重新预览。恢复不会直接触发原站导入。若已编辑导入框、重新预览或关闭弹窗，旧恢复入口失效；它只作用于当前对话框，不保存到本地存储，也不撤销已经完成的原站导入。

版本对比页 `/compare` 已翻译选择与筛选控件。版本名、数据路径、标识符及原始差异值保留原文，便于核对上游变动；这不是游戏版本译名或规则变动的独立校验。

## 背包备份与恢复

在“背包”中点击“导出”保存原生JSON备份；恢复使用背包内“导入”，不是制作页“导入装备”。粘贴后点击“继续”，核对替换当前数据且无法撤销的确认，再继续。用两件自造装备核对过完整恢复；扩展不改写备份JSON。两个已有PoE2页的恢复、切换和保存目标名称已核对；通过界面新建／重命名、跨页拖拽和跨游戏恢复仍待验收。

背包导入成功和复制到剪贴板的原生通知支持中文／双语；其他尚未核对的通知保留原文，扩展不改变原站通知的显示时长。

## 0.9.0 本地候选：攻略与划词

- 整页阅读：攻略页点扩展图标 → 翻译此页 → 检查范围 → 开始翻译。原文旁模式的侧栏默认只显示目录、当前段和异常；可切“仅侧栏”看全文。失败可从异常清单定位和重试。
- 随手划词：扩展弹窗点“启用本页划词”，关闭弹窗或侧栏均可；选中文字后点击“翻译选中文字”。需要时先在“翻译此页 → 设置”配置同一翻译服务。选区最多 6000 字符，不读取输入框或编辑器；刷新或导航后重新启用。
- 气泡点击翻译后保留；可拖动标题，或聚焦标题后用方向键移动（Shift 加快）。点击“置顶”使它位于本页其他译文气泡上方，不是系统窗口置顶。最多保留 6 个，满额时先关闭一个；后台全局最多同时处理 4 个划词请求。
- Esc 关闭当前气泡；“关闭”或“取消”只中止对应任务。新选区不取消已有翻译；原文失效或离开页面时清理相关气泡。缓存和已知词缀无需新增模型请求。未收录词缀原样保留，不会为了消除英文而交给模型猜译。
- 译文中的本段已确认术语使用轻量下划线，悬停或键盘聚焦可看英文；每个术语仅标注首次出现，歧义和未确认词不强行标注。侧栏、原文旁和气泡一致，复制仍为纯译文。
