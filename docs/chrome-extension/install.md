# 安装与使用

[下载 Chrome 中文助手](https://poe2-tools.pine2d.com/extension/) · [扩展介绍](README.md) · [隐私与权限](privacy.md)

当前公开下载版为 **0.11.0 开发预览**，尚未上架 Chrome 应用商店。攻略译文仍可能出现语义错误，请保留原文对照。具体支持范围见[兼容性记录](compatibility.md)。

## 普通用户安装

1. 从[网站下载页](https://poe2-tools.pine2d.com/extension/)取得 ZIP，也可从 [GitHub Release](https://github.com/pine2D/poe2-tools/releases/tag/ext-v0.11.0) 下载同一个安装包。
2. 解压到固定文件夹，确认其中有 `manifest.json`。安装后请保留这个文件夹。
3. 在桌面 Chrome 地址栏输入 `chrome://extensions/`，开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择上一步的文件夹。
5. 在 Chrome 工具栏的扩展菜单中找到“PoE2 中文助手”；需要经常使用时可将它固定。

开发者模式需保持开启，Chrome 可能提示扩展不来自应用商店。ZIP 需要先解压，不能直接作为商店安装包安装。普通使用无需 Node.js、pnpm 或源码；自行构建见[开发指南](development.md#从源码构建)。

## 在 CoE 使用中文

打开 [CoE Beta](https://beta.craftofexile.com/?game=poe2&language=us)，选择 **POE 2 → English**，刷新页面。扩展不适配旧版 www 站或 PoE1。

点击扩展图标查看当前页状态。打开“启用简体中文”，按需要选择“显示中英对照”；设置保存在本机，不随账号同步。若提示无法读取设置，先点“重试读取”。原站处于其他语言时，请手动切换 English，扩展不会代你更改原站语言。

### 中文显示与搜索

已收录的界面、名称和词缀会显示中文；未命中或译名有冲突时保留英文。关闭“显示中英对照”后，已识别词缀只显示中文，悬停可查看原句；开启后同时显示中英文。原站用于筛选、PoB 复制的英文内容保留。

在已支持的首页基底、制作页词缀、Data 物品／词缀、材料价格及计算／模拟器条件搜索框中：

1. 输入中文或中英混合文字。
2. 点击带英文的候选，也可用方向键选择；唯一精确匹配可直接按 Enter。
3. 由原站继续查询。条件下拉框还需在原站结果中选定具体条件。

Escape 关闭候选并回到输入框。制作与条件搜索按原站当前集合筛选候选；集合不可读取时会说明是否改用全局词典。价格数值、流程名称和备注保持原样。旧称“亵渎”可作为“渎灵”相关词条的检索别名，仍需选择候选。

### 转换中文装备文本

1. 在游戏中用 Ctrl+Alt+C 复制高级装备文本。
2. 在 CoE 打开“导入装备”，粘贴文本，点击“预览中文转换”。
3. 核对原文与英文预览。若提示“需先核对 N 行／处”，可点击“第 N 行”定位问题，修改后重新预览。
4. 允许转接时，点击“填入英文到原站导入框”，再由你点击原站 Proceed。
5. 导入后核对基底、物等、稀有度、数值、范围、等阶与授予技能。

能够完整转换的文本也可通过“复制英文装备文本”取出。交易备注与说明留在原文预览，不提交给原站。修改原文后，旧预览不能继续填入或复制；关闭导入窗口后，请重新粘贴并预览。

转换按文本与词典处理，不按基底逐个放行。数字、已有范围、等阶和多行词缀结构保留；缺少的数据不补造。装备是否合法、词缀归属与数量是否被接受，由 CoE 判断。

输入使用独立国服与台服词典，不做繁简互转。“法杖”等两服同形异义类别会提示核对；随机稀有名称、词缀组名和标签可能仍为中文，不能只凭是否还含中文判断成败。未知关键内容、歧义和损坏数值会保留原文并提示。

传奇与咒符仅供对照。当前原站可能以 `Unsupported rarity` 拒绝传奇，不应通过修改稀有度绕过。已知原站问题还包括部分腰带咒符位被拒绝或丢失、授予技能被重算、增效被再次应用；请保留原值，不删行绕过提示。

### 回填后恢复中文原文

点击“填入英文到原站导入框”后，可用“恢复粘贴原文”恢复本次完整文本（含备注），修改后重新预览。恢复不会触发原站导入，也不撤销已经完成的导入。编辑输入框、重新预览或关闭窗口后，旧恢复入口失效。

## 攻略阅读

1. 在攻略页点击扩展图标 → “翻译此页”。扩展先读取并预览正文，不会立即发送翻译请求。
2. 在“设置”的“服务 Key”中粘贴翻译服务的 API 密钥；可展开“Key 从哪里来？”查看说明。默认使用 DeepSeek，自定义 OpenAI 兼容接口还需填写地址与模型名。检查后点“保存服务并返回”。费用由对应服务商收取，“测试连接”也会发送一条简短测试消息。
3. 展开“翻译范围”，选择“整页正文／选中文字／点选区域”，再勾选需要的章节。点选区域先高亮、再点击确认；Esc 或 30 秒未确认会退出。
4. 检查已选段落与用量估算，点击“开始翻译”。切换 Mobalytics 阶段后，也需先检查新范围。
5. 在“阅读位置”选择“原文旁对照”或“仅侧栏”。默认在原文旁对照；不适合插入的内容会提示并放在侧栏。目录可跳转，段落工具可定位原文、复制或重译。

只处理当前已加载且可访问的正文，不包含隐藏、折叠内容或链接子页。空选区不会自动改成全文；取消全部章节后，需要重新选择才能开始。

点击“停止”可中止后续请求；关闭或隐藏侧栏也会停止。已发送的内容仍可能产生服务商用量。重新打开时可复用已有缓存，未完成内容需再次点击开始。

“恢复原文”移除本扩展的页内译文，侧栏已完成内容仍可查看。原文变化时请按提示重新读取。切换阅读位置、定位原文和查看用量不会重复调用翻译服务。

本段已确认的术语带轻量下划线，悬停或键盘聚焦可看英文；歧义词不强行标注，复制仍为纯译文。完整确定的词缀可以本地翻译；未收录的明确词缀保留原文。检查通过不代表整句准确，动作、条件和数值关系仍需核对。

## 划词翻译

### 临时启用当前页

在扩展弹窗点“启用本页划词”，选择文字后点击“翻译选中文字”。侧栏关闭时也可使用；翻译服务与整页阅读共用，可先在“翻译此页 → 设置”中配置。

选区最多 6000 字符，不读取输入框、密码或可编辑区域。临时启用在刷新或导航后失效；常用网站可按下一节设置自动启用。

### 自动启用常用网站

扩展弹窗 → “管理自动划词站点” → 启用常用预设或添加网址 → 在 Chrome 提示中授权。此后访问匹配页面时，加载完成即可选择文字；仍需点击翻译才发送。

填写完整目录可限制扩展的生效路径，但 Chrome 授予的是该网站访问权限。拒绝授权则不启用；移除条目会撤回不再使用的对应站点权限。“关闭本页划词”只暂停当前文档，刷新后按站点设置恢复。预设并不保证该站所有页面均已验收。

### 管理翻译气泡

气泡可复制、关闭、置顶或拖动标题；聚焦标题后可用方向键移动，Shift 加快。置顶仅表示在本页其他译文气泡上方，不是系统窗口置顶。

最多保留 6 个气泡，同时最多处理 4 个划词请求；满额时先关闭一个。Esc 关闭当前气泡；关闭或取消只中止对应任务，新选区不取消已有翻译。原文失效或离开页面时，相应气泡会清理。

复杂表格、跨域 iframe、封闭 Shadow DOM、canvas 和未加载内容有提取边界；可改选能访问的正文范围。

## 与其他翻译扩展同时使用

CoE 页应只由一个扩展翻译。多个扩展先后改写同一句话，可能出现中英混排，导致完整词缀无法匹配。

若同时使用 PoE2“说”中文，可在其“基本设置 & 导航”中关闭 `CraftofExile / CraftofExile2` 站点开关，再刷新 CoE。其他网站开关可保留。只切换本扩展的“显示中英对照”不能恢复已被另一扩展改写的原文。已复现的版本与范围见[扩展共存追查](validation-2026-10-20-extension-conflict.md)。

## 更新、关闭与清除数据

### 更新安装包

1. 从网站下载新版 ZIP，解压覆盖原安装目录。
2. 在 `chrome://extensions/` 保持“开发者模式”开启，点击本扩展的“重新加载”。
3. 核对管理页版本号，重新打开弹窗，并刷新已有 CoE 或攻略标签页。

弹窗与侧栏的“检查更新”打开网站下载页，不会自动安装。更新时沿用原安装目录和扩展条目；旧标签页里的残留译文不能证明新版已生效。

从 0.4.x 升级时，需先移除旧版再加载新版，CoE 开关将恢复默认；0.5.0 起使用固定扩展身份。

### 关闭功能

从扩展弹窗关闭 CoE 汉化，页面会恢复当前原文并撤下对应入口。攻略页可用“恢复原文”移除页内译文，用“关闭本页划词”暂停划词。

从 Chrome 管理页禁用或卸载扩展后，请刷新已有标签页，以清除遗留的扩展内容。

### 清除 Key 与缓存

在攻略侧栏“设置”中清除译文缓存，或选择“清除 Key 与翻译数据…”并确认。Key 保存在本机扩展存储中，未加密。

自动划词网站授权单独管理：在“管理自动划词站点”中移除对应条目。清除翻译数据不会自动删除站点规则。详见[隐私与权限](privacy.md)。

## CoE 流程与背包操作

### 导入、保存与恢复模拟流程

单个流程 JSON 使用“流程模拟 → 新建模拟流程 → 导入一个流程”；“载入 → 全部导入”用于原站批量备份。装备高级文本仍走“导入装备”。

在流程图点击“保存”，填写名称后再次保存。载入时请点击目标行的“载入”按钮；单击名称不会载入。当前流程可通过“返回流程图”查看，刷新后的编辑状态与保存列表是两回事。

备份使用“载入 → 全部导出”，恢复使用“全部导入”。原站会提示替换当前数据且无法撤销；恢复后仍需点击目标行的“载入”。多项、跨游戏备份仍有待验收项。

### 条件与说明

条件组的“与／或／非”和“组内匹配数量”分别设置，选“或”不会自动把数量改为 1。编辑数量或等阶后，先移开焦点、等待界面更新，再“应用更改”，重新打开核对；快速输入后立即应用曾出现旧值，重要流程可导出复核。

模拟侧栏的“查看使用说明”打开原站教程，已收录章节支持中文与双语，动图内的英文保持。预兆用途说明也只翻译已核对的整句，不代表扩展验证了制作机制。显示“来源未知”的持续伤害词条仅用于展示与搜索，不用于反向导入，也不证明属于当前合法制作池。

版本对比页保留版本名、数据路径、标识符和原始差异值，只翻译已支持的控件；方便核对上游变化，不作为规则变动的独立校验。

### 背包备份与恢复

在“背包”点击“导出”保存原生 JSON。恢复使用背包内“导入”，粘贴后点击“继续”，阅读替换当前数据且无法撤销的提示，再决定是否继续；不要使用制作页“导入装备”。

扩展不改写备份 JSON。已有 PoE2 背包页的部分恢复、切换与保存流程已有记录；新建／重命名、跨页拖拽和跨游戏恢复仍有未测项，见[兼容性记录](compatibility.md)。

## 遇到问题

先核对扩展版本、CoE 的游戏与语言设置；页面改版或出现混排时，可关闭翻译扩展并刷新，比较原站表现。

请在 [GitHub Issues](https://github.com/pine2D/poe2-tools/issues) 提供页面地址、版本、操作步骤和必要截图。隐去 Key、账号与私人内容，无需公开整份私人装备或攻略。历史实测范围见[兼容性记录](compatibility.md)，源码构建、数据开关与发布流程见[开发指南](development.md)。
