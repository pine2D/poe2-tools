# 2026-10-20 双语开关与词缀表布局修复

0.4.3 为本地候选包，未推送、部署或提交 CWS。此轮针对用户在 0.4.2 上报告的两张截图，沿用兼容修复工作树；没有调用 DeepSeek。

## 问题与修复

1. 词缀层未接收 `bilingual` 设置，始终在英文下方添加中文。现将设置传入该层：中文模式仅视觉隐藏已译出的原文；未知行继续可见。保留原站英文节点、数字、关键词身份与 `textContent`，供原站更新、筛选和复制使用。关闭扩展、移入受保护区域、变成未知文本或清理原站克隆时恢复原文。
2. 双语表头的中英文被 `nowrap` 放在同一行，挤压词缀列；仅让表头分行还不足以解决右侧装备卡占用空间后的并排布局。现让数值表头中英文各占一行，并仅在对照模式启用词缀区容器查询：可用宽度不超过 72rem 时，前后缀表上下排列。关闭对照沿用原站布局；关闭扩展移除附加样式。

纯中文模式可通过浏览器原生标题提示查看译文对应的英文原句。CoE 的英文关键词节点在对照模式可见；中文译文本身未复制一套 CoE 关键词解释系统。
