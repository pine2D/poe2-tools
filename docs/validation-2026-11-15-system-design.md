# 系统设计升级：裁定与验收

## 目标与边界

本轮从网站 0.11.0、扩展 0.11.1（`9f94358`）出发，统一网站与扩展的视觉层次、操作角色和任务状态。暗色控件只是表象，完整范围包括首页、扩展介绍、构筑交付、弹窗、阅读侧栏、翻译设置、站点管理与 CoE 自有浮层。

用户已要求将方案存入 Obsidian 并持续实施；每个关键步骤使用 Antigravity 验收，主代理核实后继续，并保留关键本地提交。本轮不包含推送、合并或公开发行。完整方案已保存为《2026-11-15 PoE2 Tools 系统设计升级方案与原型推进备忘》。

保持既有产品边界：构筑 A 单页交付，两个阅读模式，服务与限额分别保存，逐站授权，CoE 原站最终确认。冻结工坊不推进；不新增依赖、权限或真实翻译请求。工程和界面检查不能代替语义、游戏内加载、Windows 输入法及读屏验收。

## 原型检查

原型位于既有设计项目的 `explorations/2026-11-15-system/`，以同数据、同状态展示代表性现状、A 视觉统一、B 任务组织。现状是根据源码重建的模拟界面，未声称逐像素复刻生产。OpenDesign Cloud 连接失败后，由 Local Codex 延续同一在地项目；原有 34 份设计文件摘要未变。

- 9 类场景 × 3 版本，在 1440×1100 与 390×844 的独立 Linux Chrome 中检查，共 54 组无整页横向溢出或控件越界。
- 15 个浏览器流程通过，包含长第 18 行定位、输入和导出范围保持、填入后交还原站、未配置服务往返、零选择、停止、阅读 17px、设置返回滚动位置保持、待核对摘要和构筑默认交付。
- 异步结果不夺取已移开的焦点；检查中外部请求列表为空。
- 6 份 JS 语法通过；扩展模块 DOM 检查 26 项、CoE 模块 13 项通过。静态设计检测 77 条均为建议级，不当作 77 个产品缺陷。
- 第一轮发现弹窗说明堆叠与阅读头部嵌套留白，已收敛；最终代表性弹窗约 646px，阅读头部约 85px。实际扩展尺寸另行验收。
- 原型翻译、权限、CoE 操作均为模拟；导出只生成演示文本。它们不证明生产请求、真实授权或游戏文件正确。

最初的第 18 行断言错误地把完整长句写成短句，已按物理行原文改正并复跑；实际选区和滚动没有通过改产品行为来迎合错误断言。

## 原型与生产的差异

1. 原型站点曾包含暂停动作，已移除。生产只实现开启／删除，且删除授权存在共享与重叠范围保护。
2. 原型范围编辑可暂存，生产选择会立即刷新预览。迁移只改入口与组织，不虚构可取消的范围事务。
3. 生产 `busy` 同时覆盖词典、缓存预览和真实生成，不能直接映射成“正在发送”。
4. 网站入口仍应前往介绍／安装页，不能照原型跳到模拟扩展弹窗。
5. 原型字号、按钮和表面色均要通过生产令牌、尺寸、字体及对比度门禁；不将原型整份 CSS 注入产品。
