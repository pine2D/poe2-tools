## 超时根因诊断（2026-10-23 晚，接续）

- **代码未变**：`main`（4608705）与本分支之间，`packages/item-core`、`packages/build-core`、`apps/site/src/features/craft`、`data/craft` 与超时测试文件逐字节相同；`vitest.config.ts` 两边都是 `maxWorkers: 1`（串行）。同一套测试在 `main` 的 GitHub CI 上通过，verify 作业约 21 分钟。

- **结论**：本地完整门禁超时主要由宿主 CPU 吞吐波动造成，属环境因素；没有证据显示本分支代码使这些测试变慢。已保留的解析器缓存与词缀池改动只减少计算量，不改变规则。门槛、断言、并行度均未改。
