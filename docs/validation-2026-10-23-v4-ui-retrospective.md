## 方法

- 独立 Xvfb 与临时 Chrome 155.0.8059.84 品牌版。品牌版已不接受 `--load-extension`，改为通过 CDP `Extensions.loadUnpacked` 加载候选 ZIP 的解压副本；没有连接日常浏览器。
- 弹窗用真实工具栏弹窗：`chrome.action.openPopup()` 或 XTest 真实点击扩展图标。只有后者带 activeTab，划词入口与侧栏读取依赖它。原生侧栏由弹窗里真实点击“翻译此页”打开；Chrome 155 原生侧栏最窄 360px，320px 只有视口仿真。
- CoE 在真实 `beta.craftofexile.com` 的 PoE2 英文界面测试，使用自造魔法装备样本；网站使用本地 Vite、正式简繁词典和自造 `.build`。
- 翻译与连接只用本机合成 OpenAI 兼容响应，没有真实 Key、没有付费调用。
- 四批由四个只读复盘会话分别完成，主会话亲看了两条 P1 和首页示意的截图并核对源码；修正分四组进行，各组用测试先复现、再修改，并在浏览器里复验。最后由一个独立会话只读审查全部修正 diff。

## 修正

- **共享样式**：新增危险确认令牌与 `.pt-btn--danger`，并加对比度门禁；主操作禁用改为中性底、去掉钢蓝内边；网站 `.pt-check` 改为 v4 方形青铜框，600px 以下图形 22px、整行 44px；开关状态字与完整声明改用 `--fs-micro`。
- **弹窗**：读取失败显示“未读取”；重试成功后焦点回到开关，旧的延时报错不会盖住随后的成功；划词按钮请求期间保持焦点，只用文字表达状态；打开侧栏失败时错误单独成行并可重试，只有缺少侧栏接口时才提示更新 Chrome；非 http(s) 页面不显示“翻译此页”；首次说明展开或开始翻译后才记为已读；主开关关闭时对照开关写“已停用”；一次切换只重查一次页面。
- **阅读与设置**：章节选择原地更新，连续键盘操作焦点不变；忙碌时焦点交给“停止”，结束或取消确认后交回；读取失败后范围选中态与重读一致；开始按钮旁显示将发送的段数、目标服务和“正文和原文语境”字符数，与超限确认同一口径，清除服务设置后不再显示；异常按失败、待核对、说明分色并排序；禁用的开始按钮写明“先重新读取”；已确认的自定义接口显示为已确认；Key 未加密与测试连接只发一条消息的说明常驻显示。
- **站点**：页面底改为 `--page`；删除按钮与确认写出完整网址；重读、撤权刷新后焦点留在对应行（根因是撤权触发的刷新重建了行）；新增规则与已有规则范围重叠时提示。
- **CoE**：普通候选面板和“中文查询”提示进入浏览器顶层（`popover="manual"`），候选按钮仍在文档中供 ARIA 引用，不支持时退回最高层级；复制、关闭语言提示后焦点留在原处；恢复粘贴原文后直接回到可填入，之后编辑仍会标失效；空导入框、同行多条提示、填入后在原站修改的文案按实际状态改写；搜索说明行不再继承原站字体；语言提示标题与“关闭”使用 L1 子集并按持有计数注册与释放字体。
- **网站**：系列条长名显示省略号；文件项整条可点，可访问名称包含构筑名；看板右栏可切换查看当前构筑的每一份导出，与两种下载逐字节一致，“下载全部”也按阶段顺序；词典重试成功后焦点交回主区标题；扩展页章节标题改为衬线与章节线，补自动划词、完整权限和发送范围；删去安慰句与自相矛盾的说明；首页装备示意改为物品提示框样式；CoE 候选示意恢复中英两行；404 改为 v4 外观。
- **文档**：更正 `docs/design-skills.md` 顶部“网站布局待迁移”和 DESIGN 字号阶梯里“尚未映射”的说法。

## 第二轮：用户裁定后的实施

用户在首轮报告后拍板：字号改 rem（网站与阅读侧栏、设置、站点管理；弹窗与 CoE 浮层保持原尺寸），弹窗按页面类型压缩并让滚动条更低调，侧栏译文术语按类别着色并加图例，CoE 候选与导入补齐原型细节，构筑页文件按构筑分组，稀有度配色调研后补齐。

- **字号 rem**：`--fs-*` 与共享组件、网站页面、侧栏／站点样式的字号改为 rem（原 px ÷ 16），流体字号只改 clamp 两端。弹窗根字号固定 16px；CoE `l1.css` 子集保持 px（Shadow DOM 里 rem 取原站根字号）。浏览器实测：默认 16px 下 967 个文字元素计算字号与迁移前 0 差异；Chrome 默认字号 20 时网站、侧栏、设置、站点管理文字放大到 125%，390／320 无横向溢出；弹窗与迁移前逐像素一致。历史工坊 `/craft/` 冻结，未迁移；划词气泡与页内标注注入第三方页面，保持原样。
- **弹窗**：不在 CoE 页面时收起开关说明并降低行高；开关行 48px、站点管理与首次说明同一行、页脚行高略收。实测 about:blank、普通网页（含翻译与划词入口）、CoE 生效页（含首次说明）内容高度均为 600px（普通网页原为 640，CoE 原为 632）；展开说明后出现的滚动条为细窄低对比样式，悬停略亮。
- **稀有度配色**：以 PoB2 `Global.lua` colorCodes（MIT，已登记来源）与 poe2wiki 交叉核对：普通 `#C8C8C8`、魔法 `#8888FF`、稀有 `#FFFF77`、传奇 `#AF6025`。新增 `--rarity-magic`、`--rarity-rare`，并把 DESIGN 已确认的普通物品与天赋色落为 `--normal-item`、`--passive`；传奇游戏原色对黑底不足 4.5:1，名称仍用 `--unique`。首页示例戒指（两条词缀）改为魔法稀有度；词典没有核实过的国服词缀名，名称只写基底名，属简化示意。
- **侧栏术语着色**：术语识别与译文映射携带条目类别；只有侧栏译文按类别着色并显示图例，侧栏原文、原文旁插入网页的译文和划词气泡不着色；同名不同类别时只保留下划线。译文缓存不保存术语映射，缓存键不变，旧缓存照常命中。真实侧栏实测各类颜色、复制纯文本与强制色彩退回下划线。
- **CoE 增补**：候选面板显示“N 项”、类别（按词条数据域，不编造）与匹配字（加粗加下划线），可访问名称保持完整；导入两栏改为带行号的只读行列表，待核对行整行标出，“第 N 行”定位时两栏对应行描边。B3-01 遮挡修复复验仍有效。
- **构筑分组**：左列按看板系列分组、组内按阶段顺序，单文件构筑自成一组，无法解析的文件归入最后一组；窄屏系列条同样分组且不横溢；看板“切换构筑”长名单行省略。
- **中英对照长名**（用户选单行省略）：对照模式下放不下的结果卡片名称在标题栏内单行省略并补完整 `title`，对照按钮在按钮区换行；普通模式逐像素不变（`27ef632`）。
- **新发现并修复**：CoE 结果卡片出现“符文水晶法器器”式叠字。根因是原站隐藏普通／魔法物品的默认名“New Item”，扩展的中文层却显示了“新物品”，把基底名挤出标题栏。现在原站隐藏的名称不生成中文层，稀有度原地切换时同步。中英对照模式下的长名超宽随后按用户选择改为单行省略（见上一条）。
- 第二轮最终 `pnpm verify:active` 退出 0：186 文件通过／1 跳过，2084 项通过／2 跳过，测试阶段 118.08 秒；Biome 1487 文件，11 条既有 warning（中间一轮因本轮新增规则顺序多出 3 条，已调整规则顺序消除）；扩展发布闸门通过。0.11.0 候选更新为 7,370,785 字节，SHA-256 `36a1346109ebfa496c139610fcad1725c8ad13f9c7b539eceaff717442003820`，仍未公开，`release.json` 与解析器缓存改动一起留在工作区。完整 `pnpm verify` 未重跑。
