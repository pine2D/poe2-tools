# 2026-09 设计语言改版记录

状态：本地实现，在分支 `feat/poe2-design-language`；未推送、未合并、未部署，发布需用户另行授权。游戏内加载 `.build` 的效果与国服客户端叫法仍待真机验收。

## 范围与决策

- D1 素材只用自绘 SVG/CSS 与 SIL OFL 1.1 字体（Noto Serif SC/TC、Cinzel）；不使用、不热链、不描摹 GGG、腾讯、CoE 的任何素材，不使用 Fontin。
- D2 只保留深色，移除浅色主题与主题切换。D3 视觉强度采用 C「沉浸」修订版。D7 装备类型图标不进一期。
- D5 新建共享包 `packages/ui-theme`；一期改网站（M0–M3），二期在扩展分支改扩展，尚未开始。
- D6 开发依赖只新增 `subset-font` 2.9.0（BSD-3-Clause），只在构建期切分字体。
- 翻译逻辑、词典与下载的 `.build` 不变；历史工坊 `/craft/` 只冻结样式并移除主题下拉，不改版。
