# 2026-10-06 阶段分组与排序验收

源码为 main `0ed99ee` 加本轮未提交修改；网站本地版本 0.9.0。下面是本地构建与自造样本的结果，不表示已部署或游戏内可加载。

## 修复与回归

- 同一来源链接但作者或升华明确冲突时分组，切换项注明作者和升华；不完整信息与已知冲突组分开。补不同作者、不同升华、不完整信息及同名切换项回归。
- 全部阶段都有天赋时按点数排列；有零／缺失天赋时保留导入顺序，不把终局误排到开荒前。排序依据在展开控件之前显示。
- 手动上移、下移、恢复建议顺序；顺序在本次页面会话、语言重算和逐项核对往返中保留。已移除 ID 忽略，新阶段追加；原文件全被移除后，新导入文件恢复建议顺序，不残留手动排序说明；不修改翻译管线或输入字段。
- ZIP 条目顺序跟随看板；回归逐一核对重排前后每个 `.build` 文件的内容字节一致。

## 实际浏览器

Google Chrome 稳定版 154.0.8037.97，WSL/Linux Headless，本地静态构建；使用网站自造示例。

| 检查 | 结果 |
|---|---|
| 上移终局 | 看板由 1–30 / 31–60 / 终局变为 1–30 / 终局 / 31–60，焦点留在终局移动按钮 |
| 恢复建议顺序 | 恢复三列原顺序，焦点交给“调整阶段顺序” |
| 320、390、1280 CSS px | 页面无额外横向溢出；阶段表使用原有内部横向滚动 |
| 390 px 控件 | 排序 summary、上移／下移和恢复按钮均为 44 px 高；初测 summary 约 37 px，已补足 |
| 字体 | 新固定文案缺“升华调排”，已通过离线字体流水线重生成网站分片；扩展字体子集没有改变 |

本轮浏览器没有单独复验重排后的语言切换；语言重算保留顺序的判断来自会话状态与稳定文件 ID 的实现检查。

这不是对所有第三方攻略的人工分组保证；无来源、缺信息、可能被截断的名称仍保留原有边界。天赋点数只是建议排序，不能保证作者阶段顺序。游戏内加载与真实玩家任务观察仍待完成。
