# 构筑汉化使用说明

[打开构筑汉化](https://poe2-tools.pine2d.com/build/) · [返回项目首页](../README.md)

将攻略作者提供的官方 Build Planner `.build` 文件导入网页，可按装备、技能和天赋查看中英对照，并下载中文文件。处理在浏览器本地完成，不上传文件，也不需要翻译服务 Key。

## 开始使用

1. 从攻略作者处取得 `.build` 文件，拖入网页或粘贴文件内容；可以同时导入多个阶段。
2. 选择简体中文（国服术语）或繁体中文（台服术语）。两套词典独立维护。
3. 在阶段对照中阅读，或逐项查看“待核对”内容。
4. 下载当前文件，或在文件区批量下载。

工具接收官方 Build Planner 的 `.build` JSON 文件，暂不支持 Path of Building（PoB）的 XML 或分享码。

## 阅读多个阶段

同一来源链接的文件通常合为一套构筑；已填写的作者或升华明确冲突时分别显示。没有来源链接时，按作者、升华和构筑名称匹配，缺失信息不猜测归属。

全部阶段都有天赋时按点数排列，否则保留导入顺序。页面会显示排序依据；展开“调整阶段顺序”可上移、下移或恢复建议顺序。调整仅保留在当前页面会话中，影响阅读、变化对照和 ZIP 条目顺序，不改写文件内容。

## 对照与下载设置

“中英对照／译文”只改变网页的阅读方式。下载文件是否保留英文，由右上角“设置”中的“导出时保留英文原行”决定；开启后，译文视图的装备提示会标出“双语”。

“补充传奇装备中文名”默认开启。当前文件的下载入口在构筑标题旁，批量下载在文件区；同名文件打包时自动加序号。

`N` 定位下一项，`F` 切换筛选；在输入框中打字时不会触发这些快捷键。

## 哪些内容会翻译

作者备注中能确定匹配的基底名、传奇名与词缀行会翻译。未收录的词缀和名称保留英文并进入“待核对”；普通自由备注保留原文，不算识别失败。

下载只改写可翻译的备注文本，保留物品身份、天赋与技能 ID、装备槽位、等级区间和未知字段。宝石、天赋、升华和槽位的中文名称用于网页预览，不写回对应身份字段。详细约定见[文件格式](build-format.md)。

## 放回游戏前

请保留原文件。游戏内加载中文输出仍待对应客户端真机验收，网页能预览和下载不代表已确认客户端显示正常。

官方 Build Planner 使用的目录及字段说明见[文件与目录](build-format.md#1-文件与目录)；当前未验证事项见[待真机验证](build-format.md#6-待真机验证)。

## 遇到问题

在 [GitHub Issues](https://github.com/pine2D/poe2-tools/issues) 提供操作步骤、目标语言和具体未识别行即可。分享样本前请去除个人信息，无需公开完整私人构筑文件。
