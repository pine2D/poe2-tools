### 等级字段必须分开

公开页表格为 Required Level，固定目录为词缀生成等级。例如高级防御页列 43，而相符目录记录为 54；高级属性页列 44，对应目录记录为 55；完美属性页列 57，目录记录为 72。这不是已证明的版本冲突，更不是把制作物等门槛改成 43／44／57 的依据。材料掉落等级也是另一字段，不参与替换。

## 接入边界与全链验收

接入前的单结果假设同时存在于 `inspectEssences`、`prepareEssenceCraft`、实际操作、目标建议和网页选择。v89 新增统一的“材料声明 → 实际结果集合”解析；调用方复用它，不能在界面与核心各写一份特判。

1. 先接入已有充分结果依据的完美档三分支。操作增加可选的结果 ID；多结果材料必须明确选择，单结果旧操作保持原样。结果 ID 必须属于当前材料和基底，不能借新增字段指定任意属性。
2. 保存、起点导入、目标、未执行指引及全部未来步骤使用新规则版本。原 v88 及更早项目即使游标尚未到达该动作，也拒绝夹带新能力；来源指纹覆盖材料及实际属性，不把新增结果视为普通词缀。
3. 目标建议遍历全部结果，条件动作按材料预检后由用户选择本次结果。不能仅检查第一种结果而误判整个材料不可用；已有词缀冲突、破裂保护、工艺容量与结晶预兆仍逐个结果校验。
4. 网页查询和选择保留材料名称、独立结果文字及数值范围，避免重复 React key 或同名按钮选错分支；切换结果清空不再合法的移除选择。整次动作只计一份材料，预兆另外计费。
5. 验证三种结果的中文导入、现有后续制作、目标与路线、预览取消、撤销重做、文件／本机／收藏恢复及计划导出。旧单结果精华须保持兼容，所有未执行的新能力声明也检查版本。

这不是将范围缩为一件项链工具：普通三档 Infinite、防御三档及 Delirium 仍保留在完整目标内。它们需要分别确认越过普通生成资格、按基底选择防御家族和授予天赋的身份，随后复用结果集合入口；不以容易通过现有测试的虚假单结果替代它们。

CoE 的公开更新说明继续用于对照工艺标记、精华错误反馈与条件流程。本轮不读取其代码或数据。来源许可与用途见 [登记表](data-sources.md)。

- 统一结果入口应按精确材料与类别声明、明确家族身份解析；不能将展示占位补成虚构属性，也不能简单选择第一条数值相符记录。

## 2026-09-18：普通三属性资格的交集

继续寻找腰带实际获得敏捷／智慧的记录，搜索结果仍主要是材料合并说明，没有取得能区分“遵守普通资格”与“越过普通资格”的直接操作证据。不能用另一工具列出了敏捷／智慧就认定游戏允许，也不把 PoE1 的腰带精华制作记录移用于 PoE2。

对同一固定 MIT 目录逐条重算：三档材料声明覆盖的 1,748 条基底记录中，按每个属性的有序 `eligibility` 首个命中标签判断，2／4／6 档的普通生成资格在每个基底上完全一致。其中 154 条同时允许力量、敏捷、智慧。它们分布如下：

| 类别 | 同时允许三属性的目录记录 | 空白魔法起点通过现有状态校验 |
| --- | ---: | ---: |
| 项链 | 25 | 14 |
| 戒指 | 29 | 27 |
| 胸甲 | 23 | 10 |
| 手套 | 32 | 26 |
| 头盔 | 42 | 33 |
| 鞋 | 3 | 2 |
| 合计 | 154 | 112 |

后一列实际调用 `createCraftState`，使用物等100、魔法稀有度、空词缀、无来源文本的起点；这是校验探针，不是材料已执行或游戏可达数量。未通过的42条包括隐藏、暂不支持的特殊容量／锻造基底，以及需要共同固有行和已选技能的三种技能项链。技能项链缺少声明不等于永远不能使用精华；后续要沿既有起点声明单独验收。腰带20条均只有力量的普通资格，依旧不能据此决定精华的完整结果集合。

该交集允许推进一个不依赖越过普通资格假设的实施步骤：依据材料三选一说明与独立属性身份，先为三属性均具普通资格的基底提供三种手选结果。这仍是规则推导，不是154条基底的真机证明，更不代表三结果等概率。结果入口必须核对精确材料、声明占位、固定来源、九条实际属性身份及有序资格；原有状态、冲突、物等和工艺限制继续生效。其他基底不能通过“只返回普通池里剩下的一个或两个属性”伪装成完整结果。

实施须贯通查询、魔法升级稀有、结果选择、目标与准备路线、策略动作、三语回读、费用、撤销重做及全部未来历史。新版本应拒绝旧项目夹带这三种材料的新执行能力，同时保留旧报价及普通通货生成相同属性的合法历史。此审计尚未修改应用规则；跨普通资格的结果和完整模拟目标仍保留。
