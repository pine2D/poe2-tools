访问 `https://beta.craftofexile.com/?game=poe2&language=us`，使用发布 ZIP，不以开发目录替代。

| 自造红玉戒指转换 | 6 / 6 行识别；英文基底 `Ruby Ring`、物等 86、火抗 25(20–30)% 保留；点击填入后再由原站继续，原站生成结果 | 使用入库的自造普通戒指，不代表任意真实装备均可导入 |
| 原生复制 | 启用扩展的中文转换结果与无扩展隔离上下文的英文导入结果，原生 JSON 186 字符、PoB 文本 182 字符，分别逐字相等 | 真实点击可见导出按钮、读取本轮复制结果；未替换剪贴板实现 |
| 真实腰带边界 | 现有本地用户样本识别 22 / 22 行；扩展显示原站兼容性提示，英文保留 `Has 2(1-3) Charm Slot`，交易备注未进入英文提交内容 | 原站仍报无法识别该咒符位属性；保留为未通过，没有删行绕过或继续强行导入 |

CoE 控制台存在资源连接失败、广告脚本异常及原站 `resizeRun` 异常。已完成上述具体操作，不将控制台概括为“零错误”。网站控制台本轮未记录到 error/warn。

## 网站实际下载

使用网站内置的三阶段自造示例，来源对应 `apps/site/src/features/build-l10n/example.ts`。分别选择国服简体、台服繁体并点击“下载当前构筑”，读取浏览器实际生成的 ZIP。

| 语言 | ZIP | 文件数 | 核对结果 |
| --- | --- | --- | --- |
| zh-CN | 1882 字节 | 3 | 8 处允许的文本字段变化；其余字段和值、数组顺序保留 |
| zh-TW | 1881 字节 | 3 | 8 处允许的文本字段变化；其余字段和值、数组顺序保留 |

例如相同的 `Pyrophyte Staff` 分别输出“耐火长杖”“炎植長杖”，没有通过繁简互转生成结果。补充传奇名称仅添加说明文本，`unique_name` 保留。

1440 与 390 像素宽度下，页面没有文档级横向溢出，下载按钮未禁用且未超出视口横向边界；窄屏阶段表内部仍横向滚动，需要滚动到内容之后的下载区。这是现有行为，不是“下载优先”的设计目标已经实现。

文件选择器上传检查被工具的允许路径规则拒绝，故本轮使用内置示例完成实际翻译与下载；不将其写成文件选择器、拖拽或任意 `.build` 导入已验收。示例未覆盖未知字段和全部标记语法；这些仍由既有单元测试覆盖，本轮未新增真实浏览器证明。输出文件尚未在游戏内加载。

## 设计探索收敛

继续使用既有项目中的 `2026-10-24-layout/compare.html` 与 `2026-10-24-family/family.html`，没有另建活动原型或覆盖原稿。本轮没有委托 OpenDesign Cloud 生成新稿，也没有把浏览器预览写成设计生成完成。

本轮实际切换 A／B／C 的同组三阶段模拟内容，检查 A 在宽窄视口下的结果与下载；在 CoE 原型中定位未收录行，再切换核对后的预置示例，检查“填入英文”只更新原站示意框，最后的“继续”仍独立。

建议收敛为：构筑默认采用 A 的单页交付结构，B 的核对区作为主动展开的深入查看；C 暂不作为默认。CoE 保持“预览核对 → 填入英文 → 原站确认”，下一次原型补足真实密度的长文本与已知原站拒绝状态，再讨论压缩说明区。理由、代价及待选事项见 [设计迭代记录](design-iteration.md#2026-11-14-续查与收敛建议)。这是代理建议，尚未变成用户选定方案或生产变更。

## 语义质量与后续边界

本轮从旧归档只读重算了 manifest、6 个冻结输入摘要、评分分布与预算记录。最终独立复核仍为 baseline 5 个 major、candidate 7 个 major；22 个旧请求合计 41,024 tokens。账本 `halted=false` 表示未耗尽预算，不表示允许继续：开发质量门禁和独立复核均为 `passed=false`。

已准备 16 条开发集离线回归清单：全部 7 个 candidate major、5 条专名／歧义、4 条通过对照；每条带原文字节摘要、原有评分和人工核对要点。没有生成新模型输出，没有使用封存 80 段调优，没有继承旧剩余额度。具体停止线和下一周期准备见 [语义复核准备](chrome-extension/quality-reassessment-2026-11-14.md)。

后续需要的实际条件：用户选定结构方向后才做生产 UI 迁移；具备可控制的 Windows Chrome 和游戏环境后补原生操作验收；付费语义测试前另行冻结候选并明确新的模型参数、请求与 token 上限。本轮没有为这些事项设置虚假的通过状态。
