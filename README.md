# poe2-tools

《流放之路 2》（Path of Exile 2）辅助工具集。TypeScript monorepo，纯静态前端，无服务端。

## 工具

| 工具 | 状态 | 说明 |
|---|---|---|
| `build-l10n` | 已发布 0.3.0；当前工作区已实现原灰阶工作台（内容分区、对照/译文、待核对筛选与定位），尚未发布；游戏内加载与真机走查待验收 | 汉化游戏官方 Build Planner 的 `.build` 文件：翻译备注文本里的基底名与词缀行，输出可直接放进 BuildPlanner 目录的中文 `.build`，并提供中英对照预览。支持简体（国服术语）与繁体（台服术语）。 |

装备制作工作台位于 `/craft/`，支持粘贴简体中文、繁体中文和英文的 Ctrl+Alt+C 装备文本，或搜索基底创建演练起点。可设置目标、预览制作结果、查看材料花费、撤销与重做，并保存或导入演练项目。

液态情感制作已接入 13 种材料、50 个已核实映射，包括三色基础与条件效果、钻石最大混沌抗性，以及四类普通珠宝的轻蔑增容与凶残增效。移除增容后保留第三条同侧词缀，后续新增与条件指引按当前空位判断。移除对象、结果侧别和数值由用户选择以演练一种可能结果，不代表随机概率；范围珠宝及钻石的空映射交互暂未开放。完整能力与限制见 [制作规则](docs/crafting-rules.md)。咒符与传奇装备仅供解析和对比。

## 快速开始

```bash
pnpm install --frozen-lockfile
pnpm verify
```

需要 Node 24 与 pnpm 11。

## 使用 build-l10n

```bash
pnpm dev            # 本地启动静态站（先把 data/dict 同步到 apps/build-l10n/public/dict）
pnpm --filter @poe2-tools/build-l10n build   # 产物在 apps/build-l10n/dist
```

浏览器里拖入或粘贴 `.build` 文件 → 选目标语言 → 查看对照预览 → 下载。所有处理都在浏览器本地完成，不上传文件。

### 部署到 Cloudflare Pages

1. 在 Cloudflare 控制台新建 Pages 项目（直接上传类型，不连接 Git）。
2. 仓库 Settings → Secrets and variables → Actions：
   - Variables：`CF_PAGES_PROJECT` = Pages 项目名
   - Secrets：`CLOUDFLARE_API_TOKEN`（权限 Cloudflare Pages: Edit）、`CLOUDFLARE_ACCOUNT_ID`
3. 推送到 `main`（或手动触发 `deploy` workflow）。变量未设置时 workflow 自动跳过。令牌只放 GitHub secrets，不写进仓库任何文件。

### 样式的死代码扫描

```bash
pnpm --filter @poe2-tools/build-l10n scan-css
```

扫两类东西：`src/styles/*.css` 里定义了但没有任何 `var()` 引用的设计令牌，以及写了样式但没有任何
`.tsx` 用到的类选择器。**不接进 `pnpm verify`**——它靠正则匹配，对「字符串拼出来的类名」和
「只被别的 CSS 规则消费的 modifier」会误报，当成门禁只会让 CI 变吵。改完样式、或删组件之后手动跑
一次即可；有发现时退出码是 1，输出里逐条列出名字。

已知误报（跑一次会看到，不是死代码）：`.filelist__status--ok` / `--error` / `--pending`
（`FileList.tsx` 用模板字符串 `` `filelist__status--${kind}` `` 拼出来，脚本只按整串字面量匹配）；
`.w3` / `.woff2`（分别来自内联 SVG 的 `www.w3.org` 命名空间地址和 `@font-face` 里的
`Cinzel-subset.woff2` 文件名，不是类选择器，被正则误判）。

## 界面使用

导入攻略网站或作者提供的 `.build` 文件后，在文件区选择构筑，并按装备、技能、天赋分区查看。
“中英对照 / 译文”只改变阅读方式；下载文件是否保留英文，由右上角“设置”中的
“导出时保留英文原行”决定。“补充传奇装备中文名”默认开启。

待核对包含词缀未命中、基底名与传奇名未收录，自由备注保留原文、不算失败。
`N` 定位下一项、`F` 切换筛选，输入期间不触发快捷键。
当前文件下载在构筑标题旁，批量下载在文件区，同名文件打包时自动加序号避免覆盖。

界面使用系统无衬线字体，支持深色、浅色和跟随系统，不加载第三方字体。

## 装备工坊

在导航中进入「装备工坊」（`/craft/`），粘贴游戏内 Ctrl+Alt+C 复制的高级装备文本，可查看词缀分组、
阶级、数值范围及英文对照，手动保存或恢复本机项目。修改输入后需重新解析才能导出。

咒符与传奇仅供对照。已知普通装备可在网页进行指定结果的通货演练，支持具体数值与范围试掷；真实概率尚未实现。CoE 转接先覆盖已验证的稀有符文法器及六类
常规词缀；不满足条件时显示原因，原文仍完整保留。点击「在 CoE 打开」才会把适配后的装备文本带到
外站，交易备注不发送。详细限制见装备格式文档。

展开「搜索基底、词缀与通货演练」可按中英文搜索基底、调整物品等级、查看中文属性范围和等级门槛。
导入的常规词缀按整组与目录对应，已对应的冲突组会在候选池中标明。混合词缀不拆组，无法唯一对应的
内容保留待核对状态。目录来自固定 PoB2 提交，包含 1827 个基底、2550 条常规装备词缀、160 条普通珠宝词缀和 243 条单独标记的亵渎专属记录（199 装备、32 普通珠宝、12 范围珠宝）；游戏版本尚未核对，
1 个源字段异常隔离。同名基底保留不同固有属性或基础面板的变体，导入有歧义时需要选择具体条目；
来源含隐藏记录的情况明确标注。源数据不含真实概率权重，不据此计算成功率。

选择「从空白基底开始」或「从当前装备开始」，可演练蜕变、增幅、富豪、点金、崇高、混沌、剥离和神圣；每一步自行选择
合法词缀结果，确认后改变状态，支持撤销、重做和回到起点，按当前路线统计通货枚数。点金会替换原魔法词缀，
需选四条新词缀。新增词缀可指定数值或按范围试掷，神圣可同时重掷普通显式和固有属性，保留词缀档位。
试掷按显示精度逐范围独立等概率取值，属于演练假设；尚未证实游戏内部精度与分布。已明确起点品质的常规防具可估算护甲、闪避、能量护盾；技能与角色面板尚未计算，
含授予技能等级范围的基底暂不开放神圣。数值无效时不能应用，撤销重做会保留具体结果。
混沌和剥离先选择演练中移除的完整词缀组；混沌再选择新增结果。可保存演练至本机，或导出/导入 `.craft.json` 项目，
恢复原始装备、完整操作与撤销游标。恢复会检查目录/规则版本并回放所有步骤，损坏文件不覆盖当前演练。
合法旧 v2–v45 项目可核对后升级为 v46；历史范围不会被凭空赋值，新操作保存实际数值。

手套和鞋支持当前 60% 恐惧精华与已支持普通防具符文的组合：候选、草稿、当前效果、前后比较、防御估算及三语文本出口使用同一增效结果。按固定 PoB 快照逐枚向下取整后合计；移除工艺后即时还原，来源文本保留。旧 100%、其他增效与绑定效果仍待支持；取整及国服实际导出待真机验收。v35 项目完整回放检查，不能通过旧规则版本注入这类新增孔位状态。

国服腰带输入兼容“咒符位”与既有“咒符栏”写法，保留实际数量和范围。已存在的 Genesis Tree 专属施法／召唤属性可对应目录并继续演练、设置保留或数值目标；专属属性尚不支持通过 Genesis Tree 新增，普通通货候选不会因此放行。

“导出装备文本”提供当前已应用结果的简体中文、繁体中文与英文高级分组预览，可复制或下载 `.txt`。默认简体中文，按需加载本站词典；两套中文译名独立核对，切换语言不改变演练历史。保留实际词缀数值、混合组、工艺标记、固有属性、授予技能、已知品质及当前符文效果；未应用草稿不会混入。文本标明演练来源，不带原交易备注、随机名称或过时面板，也不编造目录缺少的阶级和穿戴需求。重新粘贴后可解析核对；同文档位歧义、孔内物及尚未支持的技能仍按原门禁处理。完整历史、精确孔内身份和撤销位置请保存 `.craft.json`；文本不保证游戏或 CoE 全类别兼容。基底与属性译文须唯一反查到英文原义；缺失、多义或不可逆时保留英文并逐行说明。类别值、词缀名及标签保留目录英文。目录中已知但缺中文译名的基底可用原英文名重新导入；中文文本中保留的规范英文技能也可回读，但必须与所选基底的完整固有属性核对一致。输入页打开制作目录后会补充英文身份识别，不猜译名或拼写。

「本次搭配预兆」支持六枚左右旋崇高、剥离与消抹预兆，分别搭配基础崇高石、剥离石或混沌石。
崇高预兆限定新增前缀或后缀；剥离与消抹预兆限定移除侧，混沌新增仍按移除后的合法池选择。
目标建议随所选预兆筛选，移除仍提示该侧的随机风险。确认操作后，历史与费用分别记录通货和预兆，支持撤销、重做和保存恢复。
常规通货已支持部分双枚配置：强效崇高可搭配定向崇高，消减可搭配左右旋消抹。后者使用基础混沌，先限定移除侧再求未破裂最低目录等级，新增仍可为任一合法侧；费用分别记录两枚预兆，v64 项目保留未来历史与条件指引。组合交互待真机核对；其余组合继续扩展。骨骼可使用下述方向与巫妖组合。咒符与传奇装备始终仅供对比。

基底详情的「精华与保证属性」可搜索中文材料、英文名称和属性，查看该类别的保证词缀与范围。
固定来源包含 82 种精华、698 条类别映射；594 条可对应词缀，104 条特殊效果映射尚未解析，保留原始 ID 并提示。
演练区支持前三档精华：选择当前基底对应的材料、核对保证属性与具体数值，再预览并应用。魔法装备升级为稀有，新增一组工艺词缀，接入后续通货、材料计数、撤销重做和项目保存恢复；目标提示识别已选档位及可接受替代项。
完美／腐化精华可对符合条件的稀有装备演练“移除一组，再加入保证工艺属性”：先选择材料，再选择要演练的移除结果，查看目标损失与前后变化。游戏中的移除仍是随机行为；装备已有工艺组或冲突属性时会拒绝，不能靠指定移除绕过。精华独有属性也可搜索并设为目标。
精华区可单独选择左旋／右旋结晶预兆，只让完美或腐化精华移除前缀／后缀；保证属性仍由精华决定。目标风险随实际移除池更新，无合法移除组会拒绝；切换预兆需要重新选择演练结果。预览、费用与历史分别保留精华和预兆，旧版项目不能注入此搭配。
目标区域会列出可直接推进目标的精华方案，包括精华保证档位与已接受替代档位，并按数值条件填入一组演练示例值。卡片分别说明选定移除结果和整个合法移除池的目标风险；结晶预兆仅在确实缩小池时推荐。点击方案先生成预览，确认应用后才计费、写入历史；示例数值不代表游戏必定掷出，方案也不是概率或价格最优路线。
从普通或魔法装备开始时，目标区域还会查找精华的示例准备路线：普通装备先蜕变，完美／腐化精华所需的稀有起点再通过富豪准备。路线列出每步指定结果和预计材料，点击只预览第一步；应用后根据实际装备重新计算建议。优先用准备步骤取得其他已选目标，每条路线经过完整回放验证；有限搜索未找到路线不代表游戏中不可达。未应用的路线不计费、不写入项目历史。
未解析效果、低于保证词缀等级及特殊镶嵌交互仍有支持边界，界面分别说明原因。低物等限制是工具尚未核验的覆盖边界，不代表游戏使用门槛；不使用来源 tierLevel 猜规则。特殊组合及真机验收仍待推进。

导入对照可显示工艺、亵渎和破裂词缀来源，保留英文状态尾注及独立破裂物品旗标。
状态与前后缀、词缀身份分别展示；明确标注的一组工艺词缀在身份与原文核对后可进入演练，后续神圣保留标记，移除该组才释放工艺位置。已揭示且能完整核对的稀有装备亵渎组也可继续制作，与工艺各限一组；普通通货不会生成亵渎专属词缀，移除该组后新增词缀不继承标记。项目自 v20 起记录亵渎来源指纹，比较与三语文本保留标记。

九种常规骨骼现可施加到支持的稀有装备，满词缀时指定移除结果，再固定三项候选并选定一项揭示；全程保存历史、来源和骨骼费用。未揭示期间可演练破裂，其他制作需先完成揭示；项目可保存恢复，装备文本需揭示后导出。候选属于指定结果演练，真实权重、其他预兆、其余隐藏期间混合加工及未支持来源仍待扩展，CoE 转接保持原范围。

目标区可选择“全部显式目标组”或“至少 N 组显式目标”。同组替代档位只计一组；固有数值条件和指定破裂组始终必选。部分模式允许超过同侧容量的备选清单，但必须存在满足数量且包含必选组的合法组合。达成后停止建议，路线也按相同条件结束；修改条件会取消旧搜索。数量条件随 v38 项目保存、撤销和恢复，减少目标导致数量越界时明确恢复全部，无法合法恢复则提示先调整条件。

破裂区可对至少四词缀的稀有装备演练破溃宝珠（Fracturing Orb）：预览锁定某组、核对目标数值、应用后计费。游戏随机选择词缀，页面指定的仅是演练结果。破裂组保留实际数值，后续神圣及普通、精华、满词缀骨骼的移除池跳过该组；目标指导会说明锁定数值无法再调整。已有破裂稀有装备可从完整高级文本导入，工艺与破裂标记独立保留，支持三语文本与项目回读。未揭示亵渎占位计入四词缀门槛但不能破裂，已固定的两组回响选项和消费机会保留。魔法破裂装备、真实随机概率和完整条件策略尚未开放，游戏操作待真机验收。

目标卡可要求其中一组破裂，同组已接受的替代档位共用这一要求；数值满足且已锁定才算达成。多步示例会按实际合法池补足四词缀、必要时先调整数值，再演练破裂。默认保留已有目标身份和数值，未破裂也不视作可以丢弃。路线显示每步材料与实际随机候选数量，预览不计费；游戏可能锁到其他词缀，示例不是成功率或最优方案。要求随项目保存，切换或删除目标会清除过期草稿。

腰带制作现覆盖当前快照中 15 种可用基底：搜索时声明已有咒符栏数，中文高级文本导入保留实际栏数和范围。神圣、目标建议、精华、骨骼及三语／项目回读共用该范围；旧 1–2 栏不会自动升级，无范围证据时仍可进行其他制作，神圣明确受限。隐藏／符文锻造及跨部位镶嵌腰带仍待支持，咒符和传奇仅供对比。普通候选不再误启用 Genesis Tree 制作标签；Genesis 生成与来源需另行建模。


头盔、胸甲、手套、鞋、法器、盾牌与小圆盾可从零孔搜索起点使用巧匠石打孔，再镶入或覆盖三系抗性、钢铁防御、生命、魔力、魔力再生、晕眩门槛、药剂回复与三属性符文的四个档级（12 族 48 种）。
胸甲普通打孔上限为两孔，其余已支持部位为一孔；空孔与已镶孔均计数，支持多一孔的额外掉落起点，但不能继续普通打孔。逐类上限采用社区资料，真机待验收。

搜索四种普通珠宝后，可直接浏览常规词缀池，按中英文属性、词缀身份和前后缀筛选，并核对导入装备的同组冲突。制作起点上方的“液态情感与保证属性”提供独立材料目录，可按中英文材料、保证属性、标签或 modId 查找，双侧结果完整列出；工艺不会混入普通随机池。开始演练后也能按保证属性找材料，尚未满足使用条件时仍显示已核实效果与原因。四类失落珠宝另有独立范围词缀池和常规演练；特殊珠宝与缺少来源的数据继续明确标注限制。

普通珠宝词缀增效由 v53 接入：强效的液化凶残可演练两侧 40–60% 结果，作用于反侧词缀，与命中催化品质相加后一次缩放。独立面板展示基础与有效值；神圣石、撤销、抗性条件及有效数值目标会重新计算。保存包含完整历史与三项来源指纹。高级出口保留基础掷值并写英文百分比头，中文原生头格式仍待真机样本；不会把显示值再次放大。

普通珠宝支持红玉、翡翠、蓝玉和宝钻的搜索起点与高级文本导入，魔法一前一后、稀有固有两前两后，v52 支持轻蔑增容及已有五词缀保留状态；通货、预兆、破裂、数值目标、路线与历史共用工坊。固定 MIT 来源新增 160 条珠宝词缀并隔离普通装备池，当前另有 160 条范围词缀、41 条无生成资格排除审计及 16 条工艺专属声明。v32 项目记录独立珠宝来源指纹，旧项目不能注入珠宝起点。三服固定使用说明按原文保留，其他未知语义仍拒绝；珠宝亵渎由 v71 接入颅骨、定向预兆、回响揭示与目标指引，按实际剩余容量核对；腐化由下述 v70 接入；普通珠宝已有催化品质由 v36 接入，液态工艺由 v50–v53 逐步接入。珠宝词缀只有一档，提高通货等级不会增加不存在的档位；真实权重及客户端验收仍待完成。

失落的红玉、翡翠、蓝玉和宝钻由 v67 接入常规制作：支持搜索起点、高级文本导入、2/2 固有容量、数值目标及路线。半径由当前词缀派生，显示预览和每步变化；剥离升级词缀后恢复小半径。半径与词缀冲突、替换的检查结果或无依据译文会拒绝导入。出口保留英文 Radius，中文原生标题待样本核验；v68 接入 13 种远古液态情感，包含超大半径、范围抗性、伤害类型转换与轻蔑增容，支持目标、路线、报价及历史恢复；旧版项目保留原支持边界。v69 支持已有催化品质的导入、搜索声明、效果比较及历史恢复；范围属性缺少独立缩放资料时，只给标注依据的显示估算，不判定有效目标达成。亵渎与腐化分别由 v71、v70 接入；催化剂实际施加和树上覆盖计算仍待接入。

强效崇高预兆支持一次新增两组词缀，可单独使用或搭配左旋／右旋崇高预兆，分别限制两条前缀／后缀；基础、高级与完美崇高沿各自等级规则逐条核对。组合材料分别计费，目标提示、示例路线、撤销及 v33 项目恢复共用流程。少于两个合法空位时的消费行为待核实，当前明确拒绝该子集；不将指定结果当成真实概率。

制作报价可自填神圣石／崇高石／混沌石单位下的材料单价及起点成本，最多六位小数。工作台按当前历史游标统计实际材料，路线分别估算新增成本和完成后的累计成本；缺报价与明确零成本分开，不显示伪完整总额。应用后的报价随 v34 演练项目保存，切换单位清空待填金额，不自动换算或抓取市场价。

多步路线可勾选“按自填报价优先搜索”，让已应用单价参与路线探索与同终点选择；完整已知费用优先，缺价保持未知。开启后修改报价会清除旧搜索结果，重新生成即可按新价比较。搜索有状态与候选预算，不承诺全局最便宜或随机重复制作的期望成本。

加载溶剂关系后，可预览四种抗性转换，一次处理全部适用词缀并分别指定基础数值。转换后的同类抗性保留独立身份，可继续加工并提取为不同目标；项目以 v75 记录关系来源及全部历史。缺少原关系表时须先加载再恢复。含破裂装备的整体使用和被转换工艺的来源标记尚未核实，当前演练会说明限制。

可先导入目标成品，在“制作目标”点击“从当前装备提取目标”，勾选要制作出的显式词缀。默认只要求对应档位，可另选精确基础数值或已有破裂要求；精确值是相等条件，不猜测属性优劣方向，应用后可编辑上下限。提取草稿需要确认，取消不改目标；装备、制作历史和固有目标保留，原显式替代、数量与破裂要求被新的选择替换。保存到演练收藏后，可在搜索出的空白基底或另一件导入装备上“沿用方案”，继续使用建议、路线和条件指引。

条件制作指引可编辑有序规则：组合稀有度、目标达成和前后缀空位，命中第一条后开始通货或停止。规则自带预兆配置；非法动作显示原因，应用后按当前装备重新判断。步骤上限包括当前历史中已应用的全部步骤，撤销后扣回。配置随项目保存，默认示例不代表最优路线。v40 进一步接入精华、骨骼施加及揭示、破裂动作，以及词缀组数和亵渎阶段条件；开始后复用既有结果选择、预览和应用流程。精华与骨骼施加的材料和预兆由规则固定，揭示可继续已有回响两组选择，费用按实际操作记录。v41 增加巧匠石和符文动作，可按已有孔数/空孔数范围继续制作；符文选择第一空孔或指定孔位，未知孔位不按零孔匹配，草稿显示实际覆盖对象，未执行的规则也校验镶嵌来源。v42 的指定目标组条件可只检查所选主组达到或尚不足 N 组，沿用数值、品质、替代与破裂要求；删除被引用目标时暂停指引，配置可保存恢复并修复。其他制作机制与真实概率批量模拟继续推进。


v43 可把条件规则分到多个制作阶段，选择入口和应用后的阶段，支持回连。每阶段按原有顺序匹配；实际应用的动作与规则材料、档位、预兆、孔位相同才推进，相同手动操作同样计入。阶段按历史重算，撤销、恢复及分支沿用实际材料费用；修改流程或目标会从当前装备重新开始。揭示展示候选不切阶段，最终选择才切换，阶段规则需覆盖已有候选状态。后续阶段能力见下文；批量概率模拟仍待推进。


v44 支持“仅判断并跳转”：按当前装备连续判断多个阶段，显示本次路径，再进入实际制作或停止。纯跳转不计步骤或费用；重复阶段的无消费循环会明确阻止执行。实际制作后未指定下一阶段时留在最终制作阶段，保存／撤销恢复会重新展开路径；含纯跳转的流程需先改动作或删规则才能关闭阶段模式。


v45 可为阶段中的制作动作设置“无法执行时”去向。动作开始前校验不通过时，显示具体原因并判断备用阶段；动作合法则照常执行。只记录最终实际制作的消耗，多次失败转向与纯判断混合成循环时会阻止执行。未配置该去向的规则仍直接显示不能开始的原因。


v46 支持嵌套“全部满足／任一满足／取反”，例如“普通或魔法，并且目标未完成”。条件可逐层分组、添加、删除及解包；原条件不会在包装时丢失。每规则最多 32 个节点、4 层嵌套，每组最多 4 项。未知孔位取反后仍不算满足，深层已删除目标会暂停指引并保留编辑入口。项目保存、撤销和阶段回放沿用相同判断，旧版本不能注入条件树。


分阶段流程现在提供可编辑画布：点击阶段查看规则，先选择规则输出、再点目标阶段即可连接应用后、纯判断或备用路线；工作路线可恢复默认留在本阶段，备用路线可清除。画布区分历史位置与本次判断，显示回连和自环，并可直接创建本阶段的停止规则、定位原条件编辑器。连线支持键盘选择，画布可缩放与滚动；视图操作不会修改制作草稿或材料，真正改线仍按原流程重启判断。保存使用现有 v46 字段，旧项目无需迁移；节点按声明顺序自动排列。

画布通过“打开流程画布”进入专注视图，常规演练页面保持紧凑。视图内可管理阶段；关闭后保留缩放和选择、取消未完成连线。连线时 Escape 先取消连接，再次按下返回演练；定位规则会关闭画布并聚焦原编辑器。

演练收藏可在当前浏览器保存多份命名项目，同名也保留独立副本；收藏完整历史、游标、目标、流程与报价，未应用草稿不保存。每份恢复均重新校验现有规则和数据来源，损坏收藏单独提示；最多20份、收藏区4MB，浏览器实际配额不足时明确提示失败。旧快速保存槽独立保留，清理站点数据会丢失本机收藏，请导出项目备份。

“沿用方案”将收藏中的制作目标与条件流程用于当前装备：先预览，再应用，保留当前完整历史、游标、孔位与品质声明及报价，不计入收藏原装备的材料。旧目标和流程被完整替换，未应用草稿清除；分阶段流程从当前游标重新进入入口阶段，步骤上限仍包含已有历史。两份项目及合并结果都需通过当前目录校验；不支持的新基底目标、不同固有属性的行号目标、失联条件引用明确拒绝。兼容方案可跨基底沿用，未知面板条件仍保持未知；保存恢复沿用 v49 项目格式。

祝福预兆可搭配神圣石，只调整固有属性数值，所有显式词缀及原值保持不变。手动草稿、目标建议、多步路线与条件指引共用这一范围，费用分别计一份神圣石和祝福预兆；旧咒符栏范围继续沿原证据，未知范围及授予技能仍受限。v47 项目保留该搭配，旧版不能注入操作或指引。固有数值仍可能变差，演练指定值不代表游戏随机结果。

条件指引支持装备面板范围，例如“物理 DPS 至少 600 后停止”或“护甲与能量护盾同时达标后转入下一阶段”。可选物理／元素／总 DPS、每秒攻击次数、暴击率、装填时间及护甲／闪避／能量护盾；复用现有本地面板估算，不加入技能、角色增益、暴击期望或装填循环。上下限包含端点，上限可留空；编辑后应用范围才改变规则。当前值、未知原因和已应用范围在编辑器中显示，未知值取反仍为未知。条件可嵌套并按历史重新判断；旧版不能注入深层面板条件。此功能用于条件指引，有限目标路线搜索仍沿用词缀与固有属性目标。

品质条件可选择普通／催化来源、指定催化类型和整数范围，例如“生命催化品质至少 20% 时使用催化崇高，归零后转入后续规则”。读取当前已应用装备，比较预览不影响判断；缺失品质不代入 0，已知零品质可匹配。草稿取消、实际消费、撤销及保存恢复均沿原历史重算。v55 保存这些条件，旧版本不能夹带未执行或深层品质规则。

抗性面板统计本件固有属性、显式词缀与当前符文提供的无条件火、冰、雷、混沌抗性，并计入已核对的催化品质。元素抗性合计为火、冰、雷之和，全元素抗性分别计入三项；不计算角色其他来源、抗性上限、穿透、友军或条件抗性。可将单抗或元素合计用于停止与转向条件，支持制作预览、撤销及 v49 项目恢复；v48 仍接受旧面板指标，不能注入新抗性指标。未知掷值只影响相关抗性，未核对孔位或增效规则不会被当作零；游戏实际显示仍待真机核验。


珠宝腐化（v70）：四种普通珠宝和四种失落珠宝现可指定瓦尔属性不变、11组独立强化或1–3次顺序重选，并继续建筑师追加强化／摧毁。保留已有品质、范围与合法工艺，强化不占前后缀；普通通货和液态制作在腐化后停用。预览、实际费用、撤销重做、三语装备文本及项目恢复贯通，旧项目不能注入新腐化流程。重选仍不开放破裂／工艺／亵渎交互，随机增减词缀及突破容量结果、真实概率继续待扩展。规则来源与游戏验收边界见 docs/crafting-rules.md。
